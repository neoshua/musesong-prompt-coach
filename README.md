# 妙响官方提示词规则 / MUSE SONG Official Rules

[妙响（MUSE SONG）](https://music.douyin.com/studio) 官方提示词与格式的**纯官方规则层**技能。

> 妙响是汽水音乐/抖音旗下的一站式 AI 音乐创作发行平台（前身「抖音音乐创作实验室」），支持灵感作曲、AI 作词、音乐改编（翻唱/仿写/续写）、多轨 AI 编辑器、虚拟歌手、AI MV，作品可一键发行到汽水音乐与抖音曲库。

**内容来源**：汽水音乐 AI 写歌官方飞书知识库，24 个 wiki 节点 + 8 篇正文引用 = 32 篇全文精读（2026-11-04）。

**本技能不含任何自研规则。** 过去累积的提问流程、交付模板、hook 增强、词曲咬合经验、曲风 DNA、多人编配、跨平台包装已全部删除，理由见文末。

## 几个最容易踩的官方事实

1. **没有「500 字符上限」。** 风格描述栏官方上限 **2000 字**，歌词栏 **5000 字**；但官方建议提示词 **30-60 个词**，「越精简风格把控越精准」。
2. **纯音乐靠字段，不靠喊话。** 在**歌词栏**填 `[Instrumental]` / `[Inst]` 或打开纯音乐开关，字段变灰才生效。只写中文「纯音乐」有概率冒出人声。
3. **中文段名没被禁用。** 硬约束只有三条：半角 `[]`、结构名正确、全篇统一。官方自己就用 `[前奏][主歌1][副歌]`。
4. **BPM 不是必填。** 抒情/写词类官方不建议写（会让歌词听起来赶）；卡点、舞曲、EDM 类按曲风公式写。
5. **音乐模型只有 Sway v5.0 / v5.5。** 不满意不是换模型，而是「只改 3-5 个词 → 双版本 A/B → 音乐改编·翻唱」。
