# 妙响提示词教练 / MUSE SONG Prompt Coach

面向**非专业音乐人**的 [妙响（MUSE SONG）](https://music.douyin.com/studio) AI 音乐提示词技能。

它不是一个「提示词模板集合」，而是一套**方法论**：通过结构化提问把一句话灵感补全成专业级提示词，并解释每个片段为什么这么写、写出来大概是什么效果、以及不满意时该怎么改。

> 妙响是汽水音乐/抖音旗下的一站式 AI 音乐创作发行平台（前身「抖音音乐创作实验室」），支持灵感作曲、AI 作词、音乐改编（翻唱/仿写/续写）、多轨 AI 编辑器、虚拟歌手、AI MV，作品可一键发行到汽水音乐与抖音曲库。

## 它能解决什么

| 常见痛点 | 本技能的做法 |
|---|---|
| 不懂乐理，只会说「想做首好听的歌」 | 7 步引导：类型 → 画面与情绪 → 曲风融合 → 人声 → 速度体感 → 结构 → hook，每问必带选项与「你帮我定」〔🧩 自研交互〕 |
| 写出来的歌平淡、听完就忘 | **hook 记忆点专章**：六型 hook、双钩子原则（开头 + 副歌）、三大必写项，直击模型「喜欢变化、厌恶重复」的天性 |
| 做短视频 BGM 不知道怎么写 | **纯音乐专章**：五步法、时间轴标注、三层配器、频段避让、loop 设计，15 个场景案例 |
| 中文唱出来像另一个字（倒字） | 换词不换曲：声调不同的同义词、句尾改平声、拆句 |
| 卡点对不上视频画面 | 卡点专用 BPM 换算：`每小节秒数 = 240 ÷ BPM`，在第 T 秒卡点取 `BPM = 240N ÷ T`（不用于普通写词） |
| 改了很多轮反而越改越差 | 版本管理：锁定母版 + 局部微调，而不是反复点「重新生成」 |
| 不知道某句该怎么写 AI 作词 | 歌词结构与押韵傻瓜教程、避开 AI 味的替换指令、30 秒自检清单 |

## 核心方法论速览

**官方核心公式**（`FKQK:244`，提示词 **30-60 词**效果最好）

```
[结构 + 风格 + 氛围 + 乐器 + 人声 + 其他细节]
```

按曲风另分四条公式（动感流行 / 潮流电子 EDM / 民族国韵 / 新世纪 Rap），不再是「一条九要素公式打天下」；BPM 与「不要什么」是可选，不是必填。

**三条人话原则**

1. **用画面替代形容词**——「好听」「高级感」是无效信号；「深夜加完班打车回家，车窗外是雨后的路灯」才是。
2. **卡点场景才用数字**——秒数、重复次数比修辞可控；但官方 `WNB:124` 不建议为写词硬定 BPM。
3. **先问再写**——要不要 hook（记忆点）由用户决定，技能只给建议并如实说明取舍。〔🧩 本技能服务设计，非官方流程〕

**三条按官方更正的经验**

- 做纯音乐时，**在歌词栏填 `[Instrumental]` 或打开纯音乐开关**才生效（`XieP:366`）；中文「纯音乐」单词有概率失效，不需要写三遍「无人声」，也没有 500 字符上限。
- 抱怨「生成结果平庸」时，官方做法是**只改 3-5 个词、一次出两个版本、必要时用音乐改编·翻唱保曲改词**；音乐模型只有 Sway v5.0/v5.5，没有一堆模型可换。
- 中文唱错字用官方三修法：**同音字替换后只改词重新生成 / 音乐改编·翻唱（参考音频权重 8-9）**；音色替换改不了错字。

## 示例

> 纯音乐示例：**风格栏**填下面这段；**歌词栏另填 `[Instrumental]`**（或打开纯音乐开关）才真正生效。

```
纯音乐，无人声。一段明亮轻快的日常 vlog 背景音乐。
画面是周末午后的公园，有人吹出一串泡泡，泡泡在阳光里缓缓升高后轻轻破掉。

【记忆点设计】全曲使用一个固定的四音上行动机（Do–Mi–Sol–Do），由马林巴演奏，
前 3 秒由它独奏开场；之后每 8 小节出现一次，出现时其他乐器抽空半拍，
只留它单独响一遍再全体回来。该动机在全曲保持完全一致，重复不少于 5 次，
不要每次出现都变奏。最后一次出现在尾奏，由它渐弱收尾。

【编曲】木吉他拨弦为主奏、竖琴短琶音模拟泡泡、点缀手拍与细小铃铛。
BPM 116，每 8 小节一次小变化，60 秒，可无缝循环。
低频干净轻薄，动态平缓无 drop。不要人声，不要突然的音量变化，不要拖沓的尾奏。
```

更多可直接粘贴的案例见 `references/03-case-library.md` 与 `references/06-instrumental-playbook.md`。

## 适用边界

- 面向中文用户与中文歌曲场景优化；英文歌曲同样可用，只是歌词与咬字部分的经验主要针对中文。
- 平台界面会持续迭代，本技能给的是**提示词层面的通用写法**，按钮名称以妙响实际页面为准。
- 模型侧按官方全库核实：音乐 **Sway v5.0 / v5.5**，AI MV 视频 **Seedance 2.0 / 2.5**。旧版提到的 SeedMusic / Mureka / Sodance 全库无据，已移除；Suno / Chirp 属第三方资料，不是妙响模型。
- 官方资料已收录 32 篇全文：知识库 24 个节点 + 8 篇正文引用，其中 2 篇因无权限/已删除无法获取；第三方词表与 Suno 电子书**不能当官方规则引用**。
