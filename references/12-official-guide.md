## 一、平台输入结构与硬参数（✅ 平台机制）

### 1.1 三条创作路径（`AaL9:29-36`）

| 路径 | 输入 | 说明 |
|---|---|---|
| **Agent 模式** | 多轮对话确认风格/情绪/音色 | 官方原生对话式创作 |
| **经典 · 灵感创作** | 一个文本框 | 一句话/一段情绪描述；有「优化提示词」「随机灵感」「纯音乐开关」「模型选择」 |
| **经典 · 专业模式** | **风格描述栏 + 歌词框** 两栏 | 另有模型选择、人声性别/音色、预设风格标签、上传参考音频、高级选项 |

> 「高级模式」是专业模式的另一种叫法。

### 1.2 两栏分工（关键）

- **风格描述栏**：全局风格提示词，决定「听觉效果和音乐表现」。官方明确说「可以在风格框里填一些风格提示词打好底色，**也可以选择不填**」（`MVeB:131`）。
- **歌词框**：填「歌词」或「**分段提示词 ➕ 歌词**」，决定「文字内容和段落结构」。
- ⚠️ 官方允许**风格底色 + 分段指令 + 歌词**混排进歌词框（`QCVK` 范式二、各曲风实操），并非「两栏严格互不越界」。本技能的「拆两段交付」是**服务设计**（便于复制），不是官方禁令。

### 1.3 参数速查表（都是官方数字）

| 项 | 官方值 | 出处 |
|---|---|---|
| 提示词长度建议 | **30-60 个词通常效果最好**，「不是越长越好」 | `FKQK:262` |
| 风格描述栏上限 | **2000 字** | `BKF:48` |
| 歌词栏上限 | **5000 字** | `BKF:48` |
| 其他时期界面截图 | 风格 7000 字 / 歌词 102400 字 / 1000 字（版本差异，数值不一） | `XieP:82/147`、`Om77:94` |
| 高级选项四参数 | 人声性别 / 风格权重 / 参考音频权重 / 创意发散程度，各 **1-10 档** | `Bu2:285` |
| 参考音频 | 最多 **2 个** | `Bu2:103` |
| 改词保曲权重配方 | 参考音频 **8-9（可拉满 10）**，风格权重与创意发散**尽量低** | `Bu2:58`、`Jqx:91`（图示 2/9/2） |
| 哼唱成曲 | 录制 **5-60 秒** | `AaL9:183` |
| 人声 | 可选性别/音色，**不支持指定艺人名** | `FKQK:238` |

> **官方没有任何「500 字符上限」**。总基调是「短」：`Bu2:187`「简单直接一点的提示词可能生成的结果准确哦～」、`BKF:118`「风格描述文字越精简，生成的音乐风格把控越精准」、`Jqx:89`「太复杂的提示词会起到反效果，也可以不填」。

## 二、官方提示词公式（替代本技能旧的九要素万能公式）

### 2.1 核心公式（`FKQK:244`）

```
[结构 + 风格 + 氛围 + 乐器 + 人声 + 其他细节]
```

`FKQK:246`「注意使用 [] 让结构提示词生效，如 `[前奏][氛围感合成器铺垫]`」

**组装四步**（`FKQK:248-251`）：
1. **先定骨架**（结构和风格）→ `[Intro][Verse][Chorus], 80s Synth-pop`
2. **再画皮肤**（氛围和情绪）→ `Nostalgic and dreamy, for a late-night drive`
3. **然后穿衣**（乐器和人声）→ `led by a classic synthesizer bassline…breathy female vocals`
4. **最后点缀**（特效和细节）→ `lush reverb, subtle tape saturation`

**官方完整示例**（`FKQK:255`）：
```
[Verse][80s Synth-pop, nostalgic and dreamy, for a late-night drive, led by a classic synthesizer bassline and electronic drums, with breathy female vocals, lush reverb, subtle tape saturation]
```

### 2.2 四条按曲风分发的公式（官方不是一条公式打天下）

| 曲风 | 官方公式 | 出处 |
|---|---|---|
| 动感流行 | `[速度BPM] + [核心节奏风格] + [标志性音色] + [人声质感] + [情感基调]` | `MVeB:56` |
| 潮流电子 EDM | `[速度BPM] + [核心节奏风格] + [标志性音色] + [人声质感](选填) + [情感基调]` | `XieP:65` |
| 民族国韵 | `[细分曲风] + [核心民族乐器] + [西方现代乐器/节奏] + [情绪与意境] + [人声特征]` | `JauM:65` |
| 新世纪 Rap | `[风格定义] + [核心律动描述] + [人声质感细节] + [编曲空间动态] + [混音音质倾向]` | `EWzn:67` |

### 2.3 两套字段体系

- **五核心要素**（`S03:44`）：核心曲风 / 标志性乐器编配 / 音色与演唱技巧 / 制作与节奏特点 / **客观性**——「描述必须专注于具体的音乐特征，避免使用主观赞美或总结性评论（例如，不要说『一种伟大的声音』）」。
- **七大核心维度**（`FKQK`）：乐器 / 人声 / 动态强度 / 音乐氛围 / 环境音效 / 制作特效 / 其他参数（BPM、节拍、调性、参考风格）。

### 2.4 关于 BPM：**可选，不是必填**

- 动感流行 / EDM 两条曲风公式把 BPM 列为第一项（`MVeB:56`、`XieP:65`），卡点类可按此写。
- 但 `WNB:124/342/494` 三处明确：「**不建议使用 bpm 的提示词**，ai 会根据你歌词的长短自动匹配，强行设定会让歌词听起来特别赶」。
- → **裁决**：写词/抒情类不要硬写 BPM，交给模型；卡点、EDM、舞曲类按曲风公式写。本技能 `08` 章的 BPM 换算公式只用于**视频卡点**这类必须精确对齐的场景，不作为通用强制项。
- 曲风 BPM 参考区间见本章第九节。

### 2.5 权重、留白、迭代（✅ 官方做法）

- **优先级词**：`Dominated by / Led by / Focus on`；**弱化词**：`Subtle / In the background / A hint of`（`FKQK:387-388`）。
- **何时写死、何时留白**（`FKQK:259-260`）：必须项写明 `male rap vocals`；想让 AI 发挥就用宽泛词 `keyboard melody` 而非 `piano melody`。
- **高效迭代：「不要完全重写提示词，尝试只改动 3-5 个词」**（`FKQK:389`）。
- 官方惯例一次生成**两个版本**（一版差异大、一版保留原曲基调，`Bu2:200`），且「不原地覆盖历史版本」（`Dkd:27`）。
- 避免冲突描述：「不要写 A happy, sad, energetic, calm song，选择一个主要情绪」；不要堆砌不相关乐器（`FKQK:386`）。
- 合规：不要直接用知名艺人名，改述其风格特征（`FKQK:238`）。

## 三、纯音乐的官方做法（本技能旧规则错得最明显的一处）

`XieP:366` 原文：

> **「如果要创作纯音乐，在歌词栏里输入 `[Inst]`、`[Instrumental]`、`[伴奏]`、`[纯音乐]` 即可，字段变灰即为生效～」**

配套要点：

| 要点 | 出处 |
|---|---|
| 纯音乐**不需要** `[Verse]`、`[Chorus]` 段落 | `XieP:151` |
| 改编纯音乐 BGM「记得在**歌词里**输入『纯音乐』或 `Instrumental`」 | `Bu2:182` |
| 「用仅仅用中文提示词输入『伴奏』『纯音乐』还是会有一定概率会生成带人声旋律的歌曲…**建议全部使用英文提示词，或打开纯音乐按钮**」 | `Om77:68-70` |
| 风格关键词写 `Instrumental` | `XieP:280` |
| 官方甚至允许 `Instrumental with Humming` 作氛围 | `JauM:251` |

→ **执行**：优先在**歌词栏**填 `[Instrumental]`（英文）或打开纯音乐开关；风格栏写 `Instrumental` + 曲风/配器。中文「纯音乐」单词有概率失效，不推荐单独使用。「不要哼唱」不是官方立场，`[Inst]` 字段已足够。

→ 附：`extra_Mat:22`「歌名中包含『伴奏』或 `instrumental` 的歌曲不会被推荐」——限制的是**歌名**，不是提示词。

## 四、分段提示词标准格式（✅ 官方，写歌词时照抄）

- 段落标签：`[Intro] [Verse] [Pre-Chorus] [Chorus] [Bridge] [Outro]`；短视频可 **ABABCB**（`FKQK:49`）。
- 「为每个划分出的歌词段落，创建一个对应的分段指令，该指令必须用方括号 `[...]` 包裹」「**指令必须在歌词的正上方**」（`Jdxf:41`、`QCVK:114`）。
- 配器与人声指令可分开写：`[Music: …]` / `[Vocal: …]`（`MVeB:137`）。
- **元标签内容不区分大小写**（`Jdxf:71`）；段落之间空一行；即兴/旁白用 `()`（`Jdxf:74`）。
- 歌词行数「**4-8 行…无硬性要求**」（`Jdxf:72`）。

**标准格式示例**：
```
[Intro]
[Music: 钢琴单音，雨夜环境音]

[Verse 1]
[Music: 只有钢琴与低频垫]
[Vocal: 贴耳气声，克制]
路灯把雨痕拉得很长
我数着红灯等一个方向

[Chorus]
[Music: 加入弦乐与鼓组]
[Vocal: Belting，情绪放开]
晚风替我说一句晚安
把疲惫轻轻放在路灯旁
```

### 4.1 段名语言（决定性原文）

```
JauM:158  如要在歌词框输入结构提示词，建议使用英文方括号如[]，方括号中中文和英文都可，但要注意结构名的正确性
Jdxf:14   ⚠️与 AI 交互中请尽量使用英文名
Jdxf:71   使用像 [verse]、[chorus] 这类元标签格式(元标签内容不区分大小写)
JauM:171  [前奏]-[主歌1]-[预副歌]-[副歌]-[主歌2]-…-[尾奏]
WNB:176   [主歌 1] / [预副歌] / [副歌] / [桥段] / [尾声]
FKQK:59   [前奏] / [主歌1] / [预副歌] / [副歌] / …（同一份「最终输出示例」）
```

→ **硬约束只有三条**：① 半角 `[]`；② 结构名正确（不能自造「高潮段」）；③ 全篇统一（不要中英混着用）。官方**首选英文**但**从未禁用中文**，自己还大量使用 `[前奏][主歌1][副歌]`。本技能旧铁律⑦「禁用中文段名」与官方冲突，**已废止**。

### 4.2 副歌前置（官方明确推荐，本技能旧版完全没有）

- `JauM:168`「网络爆火歌曲通常使用**副歌 [Chorus] 前置**的形式在开头就抓住听众的耳朵」，并给 4 种排布（经典抒情 / 叙事长篇 / 史诗武侠 / 简约意境，`JauM:171-177`）。
- `WNB:372-376`「**开口即高潮，金句强重复**…绝对不能主歌写 1 分钟才到副歌」。黄金结构：
  ```
  前奏(4-8s) → 副歌片段(核心金句，15 秒内必出) → 主歌1 → 预副歌 → 完整副歌
  → … → 副歌升调重复 → 尾声
  ```
- 常规顺序（`Jdxf:26`）：`前奏→主歌→前副歌→副歌→间奏→主歌→副歌→桥段→副歌→尾奏`；Rap 与 EDM 各有变体（`Jdxf:29-30`）。

## 五、写词方法论（官方）

### 5.1 押韵体系（`Jdxf:78-166`，本技能旧版几乎空白）

- **选韵看情绪**：开口呼 `a/ang/ao/an` 洪亮开阔→大气激昂；闭口呼 `i/in/ing/ü` 细腻内敛→温柔伤感；短促 `e/o/uo`→活泼/说唱（`Jdxf:88-90`）。
- **核心韵部 1-2 个，最多不超过 3 个**；主歌 an、副歌 ang 可近韵通押（`Jdxf:91`）。
- **完美韵**（光-望-茫）用在**副歌尾句、标题句**；**斜韵**（梦-懂、走-久）用在主歌，更像自然说话（`Jdxf:106-109`）。
- **押韵结构**：`AAAA` 句句押→副歌；`ABAB / AABB` 隔句押→主歌；`ABCB` 跳句押→口语化；另有内部押韵（`Jdxf:99-104`）。
- **密度**：「不用追求句句押韵，尤其主歌叙事部分，**每 2 句或 4 句押一次更舒服**」（`Jdxf:110`）。
- **换韵**：按段落功能（主歌宽松隔句、副歌密集完美韵、桥段换新韵）或情绪递进（内敛 i → 开阔 ang，`Jdxf:118-123`）。
- **押响韵**（`MVeB:373-375`）：多押 `ang`（大/放/长）、`u·ou`（酒/愁/走）、`i·ei`（悲/泪/谁）。
- **四个雷区**（`Jdxf:129-132`）：不颠倒语序违背口语逻辑 / 不用生僻韵脚（龠玥珏→月约悦）/ 查倒字（平声配平缓旋律、仄声配起伏）/ 情感最浓处**可完全放弃押韵**，「真实感比韵律感更重要」。
- 韵脚要有画面感：「写『离别』用『帆/岸/叹』比『饭/慢/看』」（`Jdxf:162`）。

### 5.2 句长、字数、标点（AI 最敏感的三件事）

- `EWzn:319-321`「**AI 对标点符号和字数对称极其敏感**」：「我走在街头看着天空」会一口气唱完；「我走在街头，看着，天空」会产生节奏停顿。「**上下句的字数和重音最好一致**」。
- **字数按体裁给区间，不是一刀切**：国风「建议一句 5-7 字」（`JauM:340`）、爆款「把长句子砍成 **7-9 个字**的短句」（`WNB:440`）、「唱得太挤就检查是不是一行字太多」（`EWzn:331`）、国风节奏 **4-2-4** 或 **5-7-5**（`JauM:329`）。
- 反例：`Hio:159-165`「八言、九言…**不要害怕字多**！关键是找到内在的逻辑重音和呼吸点」；`Hio:155` 提倡「长短结合」。→ 本技能旧版「单句≤12字」只能当作**咬合急救建议**，不是写词通则。
- **标点白名单**（`EWzn:332`）：「尽量只用 `，！？。` 以及 `[] ()`。复杂的表情符号或特殊字符会导致 AI 卡壳或者**唱出乱码音**」。
- **歌词内嵌演唱指令**（`EWzn:167-173`）：`(Breath)` 强制呼吸声 / `(Sigh)` 叹息 / `(Whisper)` 耳语 / 行尾 `...` 诱导气声延长尾音。
- **空格造顿点**（`Hio:234-235`）：高级模式填歌词时输入「我 在 等你」手动制造停顿。
- `Hio:186-214` **五步造句法**：定核心意象 → 选句式（四/五/六/七/八言）→ 试分割落点 → 考虑押韵与声调 → 口语化微调（「歌词毕竟是用来唱的，不是用来看的！」）。

### 5.3 金句创作法（`WNB`，2 万字）

**三大范式**：热点锚定型 / 原创共情型 / 经典复用型（`WNB:37-40`）。

- **热点锚定型**：`WNB:165`「**爆款金句 = 热点原生核心梗 + 节奏对仗/重复强化 + 普适情绪延伸**」；`WNB:167`「**15 秒内必须出核心梗，整首歌核心梗重复 3 次以上**」；全程押宽韵。
- **原创共情型**三特质：普适性、具象化、传播性（`WNB:265`）。核心手法：「不说『我想你』，而是写『**你的牙刷，我还摆回了原位**』」（`WNB:269`）。
- **四个万能公式**：
  1. 自我和解式：`我不必【别人的期待】，我只要【自己的选择】` → 「我不必光芒万丈，我只要活得坦荡」
  2. 遗憾留白式：`我还在【保留的习惯】，只是【少了你的痕迹】` → 「我还留着那年的车票，只是再也没去过那座城」
  3. 细节扎心式：`【一个旧物件】，藏着【没说出口的情绪】` → 「旧手机存着你的地址，我没删也没再开启」
  4. 温柔自愈式：`【自然意象】+【情绪治愈/与自己和解】`
- **落地**（`WNB:390-442`）：主歌 = 时间/地点 + 具象场景 + 动作细节 + 淡淡情绪；**副歌固定 4 句**（前 2 句铺垫、第 3 句转折、第 4 句砸金句，或首尾都放金句）；长句砍成 7-9 字；开头/副歌/结尾重复核心金句。
- **经典复用型**三公式：原话直用型（金句放副歌 C 位）/ 意象化用型 / 反差颠覆型（`WNB:549-568`）。
- **AI 味规避**（`WNB:400`）：「**便利店、关东煮、地铁，是 ai 生成歌词会经常出现的意象…也可以特地告诉 ai 规避这些词**」。

### 5.4 意象与「诗词歌赋」手法

`Jdxf:172`「从『表达情绪』到『构建意象』，不要直接说『我很难过』，而是构建一个场景」。官方讲的四法（`Jdxf:172-264`）：
1. **隐喻与象征系统**：选一个核心隐喻贯穿全篇（都市丛林 / 数字牢笼 / 齿轮螺丝钉）；
2. **细节叙事与矛盾陈列**：「卖掉了收藏的球鞋换麦克风，在早餐钱和录音费间做选择困难症，妈妈的叹息是每晚的背景音」；
3. **语言陌生化**：「时间在墙角霉变」「一段很水泥的沉默」；
4. **结构设计与留白**：起承转合，Verse1 呈现 / Pre-Chorus 攀升 / Chorus 爆发 / Bridge 升华 / Outro 余韵；「每四句内完成一次起承转合」（`Jdxf:264`）。

国风专项：半文半白（`JauM:320`）、4 类意象词库（自然景观 / 古典器物 / 情感动词 / 地标色彩）、**叠词大法**（悠悠、滚滚、冷冷清清，`JauM:341`）、对仗工整。

> 注：「赋比兴 / 顶真 / 用典」官方**没有**作为清单提出（官方未提及）；用典实操藏在 `WNB` 经典复用型里。

## 六、AI 唱错字 / 咬字 / 乱发挥（`Jqx` 全篇，官方三修法）

现象：多音字唱错、**普通话突然串成粤语**、吐字不清（「落地窗」→「落的窗」、「依稀记得」→「依he记得」）。

### 修法 1 · 同音字替换（`Jqx:36-44`）
> 「把『稀』换成『西』或『细』，**音调不一样没关系，不影响唱出来的效果**」；「**只改编歌词，其他的不动，重新生成便可**」。风格描述不变则音乐风格大差不差。

### 修法 2 · 音乐改编·翻唱（官方推荐 👍，`Jqx:52-93`）
改词不改曲，「对**单个字**进行精准修改」。
- 风格描述「简洁明了填 R&B、流行即可，**太复杂的提示词会起到反效果，也可以不填**」；
- **权重配方**（`Jqx:91`，图示 2/9/2）：「参考音频的权重我们调的很高，大概 **8-9**，风格和创意发散程度的权重则**尽可能低**」。

### 修法 3 · 音色替换 / 智能演唱（`Jqx:99-131`）
能换音色，但「**这种做法并不能实现更改错字的效果**」——别走错路。

**其他补充指令原文**：
- `MVeB:103`「用中文提示词生成的歌曲中文咬字更准确哦」；
- `EWzn:333` 粤语串台用同音词替换或不改旋律重唱；
- `Om77:255` AI 作词指令「写一段符合这个伴奏的歌词…verse、chorus 等段落提示词用 [] 框起来」；`Om77:248`「不要让 ai 根据 Beat 生成歌词，ai 会默认你想要 rap」；
- `JauM:308` 保韵改词指令「保留原本的韵脚将 xxxx 改为符合人类日常表达的字眼」。
