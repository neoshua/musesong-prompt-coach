# 记忆点（hook）设计：通用章节（歌曲与纯音乐都适用）

> **这是本技能里最重要的一章。** AI 生成的音乐最常见的失败不是"难听"，而是"**平庸、听完就忘**"。

## 适用范围：**所有音乐**，不是纯音乐的专利

带人声歌曲、纯音乐 BGM、改编作品、AI MV 配乐——**全都适用**。差别只在"hook 由什么承载"：

| 作品类型 | hook 的主要载体 | 额外的独门武器 |
|---|---|---|
| **带人声歌曲** | 旋律动机 + 鼓/贝斯 pattern + 和弦进行 | **歌词 hook**（歌名句、短句重复、副歌后的呓语短句）+ 人声质感（沙哑/转音/adlib） |
| **纯音乐 / BGM** | 旋律动机 + 节奏 pattern + 和弦进行 | **音色 hook（signature sound）** + **固定音型 ostinato**（没有歌词，只能靠这两样） |
| **改编（翻唱/仿写/续写）** | 沿用原曲 hook 的动机 | 换音色重写 hook（"同一个动机换成 XX 演奏"） |

**通用底层逻辑完全相同**，本章所有技巧对两类音乐一视同仁；只有"载体表"这一层需要按类型选。

## 两条通用规律

1. **开头和副歌同等重要，都要有钩子。** 好音乐通常配置"双钩子"：**开头钩子（intro hook）** 负责留住人（前 3~8 秒），**副歌钩子（chorus hook）** 负责让人记住和传唱。二者**必须同源**——副歌的钩子动机，在开头先用它的片段单独亮一次，前后呼应。
2. **但并非所有音乐都需要 hook，必须由用户决定。** 见第六节——技能要主动给出建议与取舍，最终选择权交给用户。

## 一、为什么 AI 音乐天生平庸

| 原因 | 后果 |
|---|---|
| 模型优化的目标是"每一段都合理"，不是"有一段特别抓人" | 全曲平均用力，没有峰值 |
| 模型天然倾向**持续变化**，怕生成重复内容 | 同一个动机每次出现都被"即兴变奏"，听众记不住 |
| 缺少"重复次数"这个概念 | hook 可能只出现一次就被换掉了 |

**所以写提示词时必须显式对抗这个倾向**——这是本章所有技巧的共同原理。

核心对照：

| 常见写法（无效） | 有效写法 |
|---|---|
| "副歌要抓耳" | "副歌前两拍由一个固定的四音上行动机构成，全曲原样重复不少于 4 次，不要每次都变奏" |
| "加一个记忆点" | "前 3 秒就要出现这个 signature 音色：清脆的马林巴四音下行；之后每 8 小节用它做一次转场提示" |
| "要有洗脑感" | "post-chorus 段插入两小节的纯哼唱式 '啦—啦—啦' 短句（无人声则用乐器演奏同一动机），连重复两次" |

## 二、hook 的六种类型（按传播力排序）

| 类型 | 说明 | 例子 | 适用 |
|---|---|---|---|
| **① 旋律 hook** | 3–7 个音的短动机，容易哼出来 | "登登登登"式四音动机 | 歌曲、vlog 主题曲 |
| **② 节奏 hook / 鼓点 hook** | 固定的鼓 pattern 或拍手 pattern | 每小节第 2、4 拍的拍手与响指 | 短视频卡点、舞蹈类 |
| **③ 音色 hook（signature sound）** | 一个辨识度极高的音色贯穿全曲 | 口哨、马林巴、音乐盒、竹笛、8-bit 音 | **纯音乐的最强武器** |
| **④ 固定音型 ostinato** | 一段不断循环的琶音/低音音型 | 持续的吉他分解和弦动机、循环琶音 | 纯音乐、BGM、游戏配乐 |
| **⑤ 和声 hook** | 一套抓耳的和弦进行反复用 | 4536 进行、卡农进行 | 抒情、流行 |
| **⑥ 动态 hook** | 靠"留白/抽空/落点"制造记忆 | 副歌前半拍空白、某处突然只剩人声 | 转场、高光时刻 |

**最强的组合**：③音色 hook + ④固定音型（纯音乐）/ ①旋律 hook +⑥动态 hook（带人声歌曲）。

## 二·B 开头钩子（intro hook）：留住人的那一秒

**为什么单独讲**：短视频时代，前 3 秒决定是继续看还是划走；听歌也一样，前奏如果平淡，很多人根本听不到副歌。**开头钩子是独立于副歌钩子的一道工序**，两者都要写，而且必须同源。

### 开头钩子的五种套路（按场景选一种）

| 套路 | 写法 | 适用 |
|---|---|---|
| **① 签名音色独奏开场** | 前 3 秒由 hook 的乐器/音色单独把动机弹一遍 | 纯音乐、vlog、任何需要"听觉商标"的作品 |
| **② 副歌前置（pre-hook）** | 开头先给副歌最后一句或一个高辨识度的短句，然后才进入主歌 | 传播向歌曲、短视频音乐 |
| **③ 节奏先行** | 前 2 秒先单独响鼓点/拍手/响指，旋律再进 | 卡点、舞蹈、潮流内容 |
| **④ 抽空对比** | 先安静（pad/人声哼唱/环境声）半拍到一小节，突然全体进入 | 转场、情绪型视频、影视感片段 |
| **⑤ 歌词金句开场** | 用副歌的歌名句或一个问句直接起手，再进主歌 | 带人声歌曲 |

### 开头钩子的通用写法模板

```
开头钩子设计：
前 [2~3] 秒采用 [套路类型] —— [具体做法，例如"由马林巴独奏一遍那个四音上行动机"]，
音量清晰靠前，混响小于主体段落（听起来更近）。
这个开场用的就是副歌 hook 的第一个小节（同源），在第 [X] 秒的完整 hook 出现时形成呼应。
```

⚠️ **同源原则**：开场用的动机必须和后面重复出现的 hook 是同一个（或它的片段）。开场很抓、后面不重复 = 头重脚轻；副歌很洗脑、开场没铺垫 = 观众没机会听到。

### 一定不要做的事

- 不要再提示词里写"前奏慢慢铺垫"——AI 很可能铺 20 秒才进主题（纯音乐尤其容易犯）
- 明确写："**第 3 秒内就要进入主体，不要冗长的前奏**"

## 二·C 完整作品的 hook 时间轴布局（通用模板）

一首"能传播的歌"，hook 通常这样分布。**这是带人声歌曲与纯音乐通用的骨架**：

| 时间点 | 位置 | hook 形态 | 作用 |
|---|---|---|---|
| 0–3 秒 | 前奏 | **intro hook**：签名音色独奏 / 副歌动机的第一小节 | 留住人 |
| 主歌 | verse | **hook 的影子**：低音型、吉他 riff 或一小段动机片段（音量退后） | 埋记忆，不抢主歌叙事 |
| 副歌前 | pre-chorus | 半拍留白 + 动机加速/重复 | 制造期待 |
| 副歌 | chorus | **chorus hook**：全曲最强形态（高音区/全奏/drop） | 被记住、被哼唱 |
| 副歌后 | post-chorus | 两小节的短句或动机原样再走一遍（常用"啦—啦—啦"式） | 加深记忆，短视频最爱截取的一段 |
| 桥段 | bridge | **反向 hook**：抽空或倒转，只留动机的一个音 | 避免疲劳，制造新鲜感 |
| 尾奏 | outro | **最后一次呼应**：由 intro hook 的音色独奏渐弱收尾 | 余韵，让人想重听 |

**重复规律**：同一个动机全曲出现 **3~5 次**（少于 3 次记不住，多于 6 次易腻），其中至少 1 次在开头、2 次在副歌及其后、1 次在尾奏。

## 三、三大必写项（缺一项 hook 就会失效）

任何 hook 指令都必须同时写清这三件事：

### 1. 形式（它具体是什么）
写清楚**音数、走向、音色**：
> "一个四音的上行动机（Mi–Sol–La–Do），由马林巴演奏"
> "一小节的口哨短句，两个音重复三次"
> "持续循环的吉他分解和弦动机，每小节从头重弹"

### 2. 位置（它出现在哪里）
**通用原则：开头必须占一位（留住人），副歌必须占一位（被记住），尾奏再呼应一次（余韵）。**

- **开头（传播向作品必写，前 3 秒）**
  > "前 3 秒由它独奏开场" / "前 2 秒先单独响一遍这个节奏型" / "用副歌 hook 的第一个小节当前奏"
- **副歌与 post-chorus（记忆点主战场）**
  > "副歌第一句就是它" / "副歌后接两小节，所有乐器停一下只留它单独走一遍"
- **段落与转场处**
  > "每个段落的开头都先响它一次" / "第 12 秒的转场重音之后立刻接它"
- **尾奏**
  > "最后一次出现在尾奏，由它渐弱收尾"

**传播向的黄金位置**：**前 15 秒内必须第一次出现**（短视频划走就在前 3 秒），全曲出现 **3~5 次**，尾奏再收一次。
**双钩子原则**：开头钩子（intro hook）与副歌钩子（chorus hook）要**同源**，即副歌的动机在开头先亮一次片段——这是"既留住人又让人记住"的标准配置。

### 3. 重复与一致性（**最关键，也最常被漏掉**）
必须显式压制模型的"变奏冲动"：
> "这个动机在全曲**保持完全一致**，不要每次出现都改变旋律、音色或节奏"
> "重复不少于 4 次"
> "伴奏可以变，但这个动机必须原样保留"

## 四、纯音乐怎么做 hook（重点）

没人声就没法靠歌词带记忆，纯音乐要抓住这两样：

**① 固定音型 ostinato（循环动机）** —— 纯音乐记忆点的王道
```
一段四小节的马林巴循环音型贯穿全曲：
每小节的第一拍是一个上行四音跑动（Do–Mi–Sol–Do），后三拍留白，
这个音型从头到尾不改变，只换上方的和声。
它同时也是全曲的转场提示，每次段落切换都由它引出。
```

**② 签名音色 signature sound**
```
全曲使用一个统一的 signature 音色：明亮的木琴（马林巴）。
无论编曲怎么变，这个音色出现时听众就知道是这条旋律。
前奏由它独奏开场，副歌它由作为主奏延续，尾奏由它收尾。
```

**③ 纯音乐的 post-hook（短视频最爱）**
```
每 16 小节插入一次两小节的"小钩子段"：
所有乐器停一下，只由马林巴单独弹一遍这个四音动机，然后全体回来。
这个"抽空—单点—回来"的结构就是记忆点。
```

## 五、带人声歌曲的 hook 写法

> 歌曲比纯音乐多一个最强武器：**歌词 hook**。而且歌曲同样需要开头钩子。

**开头钩子（歌曲专属，别漏掉）**

| 套路 | 直接抄的指令 |
|---|---|
| 副歌前置 | "前 2 秒先用副歌最后一句或一个高辨识度短句开场，再进入主歌" |
| 清唱 hook 开场 | "开头 4 秒为无伴奏的清唱短句，只用一句，第 5 秒伴奏全体进入" |
| 动机先现 | "前奏由吉他（或钢琴）单独弹一遍副歌的第一句旋律，人声紧接着进主歌" |
| 金句问句开场 | "用一个问句作为第一句歌词，并在副歌最后给出回答" |

⚠️ 歌曲最容易犯的错：前奏铺 15~20 秒才唱。**务必写"第 3~5 秒内人声进入，不要冗长前奏"**。

**副歌与其余位置的 hook**

| 写法 | 直接抄的指令 |
|---|---|
| Title line（歌名做副歌首句） | "把歌名《xxx》放在副歌第一句和最后一句，中间加一个重复的短句" |
| **歌名闭环（Title line 加强）** | "副歌首句与末句都嵌入歌名，如《百泉》：'百泉湖水落千年……百泉还似旧时暖'"——首尾都扣题，与 09 章「副歌重复句」叠加使用 |
| Post-chorus 短句 | "副歌后接两小节的 '啦—啦—啦' 哼唱或 '何必—何必' 式短句，第二遍副歌后重复一次" |
| 副歌前置动 | "副歌第一句进入高音区，前面留半拍空白只留一个小节的呼吸声" |
| Adlib 记忆点 | "最后一遍副歌加入两句自由转音的 adlib" |
| 呼应与回答 | "主唱一句短句，和声立刻重复最后三个字"（call & response） |
| 乐器 obbligato hook | "每一遍副歌的头两拍都有一小段固定的吉他/弦乐装饰句，全曲保持一致" |

**歌曲的通用 hook 模板（直接套）**
```
记忆点设计（歌曲版）：
① 开头：前 3 秒由 [乐器/清唱] 先奏一遍副歌 hook 的第一个小节；
② 副歌：把歌名《xxx》放在副歌首句，前面留半拍空白，旋律进入全曲音最高处；
③ post-chorus：副歌后两小节用 '啦—啦—啦' 式短句重复副歌动机的节奏，连两遍；
④ 尾奏：最后一路由开头那个音色独奏渐弱收尾。
该动机全曲原样出现不少于 4 次，不要每次都变奏。
```

## 六、先问用户：**这条音乐到底要不要 hook**（必须让用户决定，不要替他定）

hook 是手段不是目的。**强 hook 意味着更强的辨识度，也意味着更抢注意力、更容易听腻**。所以每次做传播向之外的作品，都要把选择权交给用户。

### 必问的两个问题（带建议，用户可直接选"你帮我定"）

**问题 1：这段音乐是要被记住，还是只想托住画面/内容？**
- A 想让人记住、希望能传播、做成账号的听觉标识 → **推荐加 hook**
- B 只想托住画面和台词，不需要观众注意音乐 → **建议弱 hook 或不要 hook**
- C 你帮我定

**问题 2：如果要加，强度选哪一档？**
- 轻度：一个签名音色贯穿，动机不那么明显地重复 —— 有统一感，不抢戏
- **中度（大多数内容推荐）**：动机每 8 小节重复 1 次 + 签名音色
- 强洗脑：前 3 秒出现 + 全曲重复 5 次以上 + 抽空小钩子段 + 尾奏收束 —— 传播力最强，也最容易听腻

### 建议对照表（只是建议，最终由用户拍板）

| 用途 | 建议 hook 策略 | 理由 |
|---|---|---|
| 短视频 / 系列 vlog / 账号主题曲 | **强**（开头 + 副歌双钩子） | 传播优先，需要听觉商标 |
| 日常 vlog 单次配乐 | 中～强度（至少一个 signature 音色） | 有记忆点又不喧宾夺主 |
| 口播、课程、讲解 | **弱**：低强度，或明确写"不要反复出现的短动机" | hook 会把注意力从内容上拉走 |
| 学习、专注、冥想 | **不要**：明确写"不要旋律钩子、保持稳定不变化" | 记忆点=干扰源 |
| 长时间垫底（展览/门店/活动暖场） | **不要**：平缓连续 | 重复次数太多会令人烦躁 |
| 完整单曲（打算发行） | **强**：intro hook + chorus hook + post-chorus + outro 呼应 | 商业化作品的标配 |
| 品牌宣传片 | 中～强（一个品牌音色贯穿） | 需要品牌资产沉淀 |

### 必须如实告知用户的取舍
- 加了 hook：**更容易被记住和传播**，但更容易听腻（同一条 BGM 反复用会疲劳），且会抢注意力；
- 不加 hook：**更耐听、更服帖画面**，但播出后没人记得，几乎没有传播价值；
- 折中：**保留一个 signature 音色，不做强烈重复** —— 多数用户的实际最优解。

> 用户一旦选定，就把对应策略写进提示词；用户说"你定"，默认给**中度 + 开头钩子**，并在交付里说明"这是默认档，想要更强/更弱告诉我一声就能改"。

## 七、hook 强度分级（按需取用）

| 强度 | 做法 | 适用 |
|---|---|---|
| 轻度 | 一个签名音色贯穿，ostinato 每小节循环 | 品牌统一感、vlog 系列 |
| 中度 | 旋律动机每 8 小节重复 1 次 + 签名音色 | 日常 vlog、轻传播内容 |
| 强洗脑（传播向） | 动机前 3 秒出现 + 全曲重复 5 次以上 + post-hook 抽空段 + 尾奏收束 | 短视频、挑战、账号主题曲 |

## 八、可直接插入任意提示词的 hook 指令片段（抄这些）

**开头钩子专用（留住人的那 3 秒，任何作品都可加）**
```
开头钩子：前 3 秒必须抓人，采用 [签名音色独奏 / 副歌动机的第一小节 / 单独的鼓点节奏]
作为开场，音量清晰靠前、混响小于主体段落（听起来更近）。
第 3 秒内进入主体，不要冗长的前奏铺垫。
这个开场素材与副歌 hook 同源，在副歌出现时形成呼应。
```

**歌曲版开头钩子**
```
前 3 秒由副歌 hook 的旋律动机单独演奏一遍（或一句无伴奏清唱），
第 4~5 秒人声直接进入主歌，不要 15 秒以上的长前奏。
```

**通用型（旋律 hook 全曲贯穿）**
```
记忆点设计：一个由 4 个音组成的下降动机（Sol–Mi–Re–Do），
由 [乐器] 演奏，在全曲保持完全一致，重复不少于 5 次。
出现位置：①前 3 秒独奏开场 ②每个段落开头 ③第 X 秒转场后 ④尾奏最后一次。
伴奏可以变化，但这个动机必须原样保留，不要每次都变奏。
```

**vlog 传播型**
```
全曲使用一个统一的签名音色（马林巴/口哨/音乐盒），
前 3 秒由它独奏一段四音动机开场；之后每 8 小节用它做一次"小钩子"：
所有乐器抽空半拍，只由它单独弹一遍，然后全体回来。尾奏由它收尾并渐弱。
```

**纯音乐 ostinato 型**
```
贯穿全曲的固定音型：一段四小节的 [吉他分解/琶音/贝斯] 循环音型，
每小节第一拍为一个上行跑动，后三拍留白，全曲不改变音型本身，
只更换其上方的和声与配器厚度。这个音型是听众记住这条曲子的锚点。
```

**卡点/节奏型**
```
节奏 hook：每小节第 2 与第 4 拍为清晰的拍手 + 响指，
全曲保持稳定，副歌加密为连续八分音符的拍手；
这个节奏型在前 2 秒就单独出现一次作为预告。
```

**歌曲副歌型**
```
副歌 hook：副歌第一句为全曲音最高处，前面留半拍完全空白；
歌名作为副歌首句与末句；副歌结束后接两小节 '啦—啦—啦' 风格的短句呼应，连唱两遍。
```

## 九、交付前的自检清单（通用）

**钩子检查（开头 + 副歌，两项都要过）**
- [ ] **开头**：前 3 秒有钩子吗？没有的话，观众在划走之前根本听不到你的副歌
- [ ] 开头钩子和副歌钩子**同源**吗？（不是同一个动机 → 前后割裂）
- [ ] **副歌**：hook 在**前 15 秒**（最好前 3~5 秒）就有铺垫吗？
- [ ] 全曲重复了 **3 次以上**吗？（少于 3 次 = 记不住）
- [ ] 每次出现是**原样重复**还是被模型变奏了？（听两遍对照）
- [ ] 这个动机能不能**随口哼出来**？（哼不出 = 太复杂，音数减到 3~5 个）
- [ ] 它是**音色/节奏/旋律**里最容易辨认的那一项吗？
- [ ] 尾奏有**最后一次呼应**吗？（决定余韵）
- [ ] **用户确认过强度吗？** 若这条音乐是背景用途（口播/学习/长时垫底）：是不是 hook 太抢、影响画面了？→ 降一级强度

## 十、失败诊断

| 症状 | 病因 | 改法 |
|---|---|---|
| 听着还行但记不住 | 没有 hook，或 hook 只出现 1 次 | 用第八节通用型指令，明确"重复不少于 5 次" |
| hook 每次都被变奏 | 没写"保持完全一致" | 加"不要每次出现都改变旋律、音色或节奏" |
| hook 出现太晚，用户已划走 | 位置没指定 | 加"前 3 秒由它独奏开场" |
| **开头平淡、前奏拖沓（最常见）** | 没写开头钩子，也没约束前奏长度 | 加第八节的开头钩子片段 + “第 3 秒内进入主体，不要冗长前奏”；歌曲写“第 3~5 秒内人声进入” |
| 开头很抓但后面接不上 | 开头 hook 与副歌 hook 不同源 | 改成“开场用的就是副歌 hook 的第一小节”，两处统一为同一个动机 |
| hook 只在副歌有、开头完全没有 | 漏了 intro hook | 按二·B 节补一条开头钩子（双钩子原则） |
| hook 抢了画面/台词 | 强度过高，用户其实只需要背景音乐 | 降一级：保留签名音色，去掉抽空小钩子段；或回到第六节让用户重新选强度 |
| hook 太复杂哼不出来 | 音数太多 | 减到 3~5 个音，音程控制在八度内，走"跳进 + 级进" |
| hook 抢了画面/台词 | 强度过高 | 降一级：保留音色 hook，去掉 post-hook 抽空段 |
| 想要系列统一感 | 缺签名音色 | 全系列固定同一个 signature 音色 + 同一个 ostinato |
| 想要更强的传播性 | 只有单一 hook | 组合使用：旋律 hook（前 3 秒）+ 节奏 hook（卡点）+ 动态 hook（抽空）三重叠加 |

## 十一、系列化：让多首作品听起来"是一家人"

地方文旅、品牌、账号矩阵常需要**同一主题出多首**（如百泉湖：一首纯音乐 + 一首歌曲）。单个作品的 hook 思路不够用——系列要的是**跨作品的听觉标识**：观众听到任意一首，就知道"这是那个地方/那个牌子"。

### 三固定

| 固定项 | 说明 | 例子 |
|---|---|---|
| **签名音色** | 全系列用同一个辨识度音色 | 系列都用古筝泛音 |
| **同一个动机** | 所有作品共享一个 3~5 音短动机，在不同作品里可换乐器/载体演奏 | 纯音乐的水滴动机 = 歌曲版人声哼鸣 + 古筝泛音继承 |
| **同一套参数语言** | BPM 区间、调式明暗、混响质感一致 | 全系列 BPM 68±8、慢速、湿润混响 |

### 写法（系列里每一首的提示词都写）

```
本作品属于 [系列名] 系列：全系列使用 [签名音色] 与 [动机描述]，
本曲中该动机由 [本曲的载体] 演奏，重复次数与出现位置要求同系列保持一致。
```

### 双版本策略（地方宣传标配）

**一首纯音乐**（宣传片 / 讲解 / 延时空镜 BGM）+ **一首歌曲**（传播、发行），两版共用同一动机——观众在片子里听到的"水滴声"，在歌里由人声哼出来，这就是系列感。交付时两版给同一张参数表（BPM/调式/动机），改一版另一版跟着改，防止系列漂移。
