# 妙响各功能模块 · 提示词案例库

每个案例包含：**适用场景 → 可直接复制的提示词 → 逐条解释 → 预期效果 → 变体/下一步**。
提示词均按"粘贴即用"的标准写好，用户可在妙响灵感模式/专业模式、AI 作词、音乐改编、AI MV 中直接使用。

---

## 模块 1 · 灵感作曲（一句话出歌，适合零基础）

### 案例 1.1 城市夜归抒情（最容易出效果的新手第一款）

**适用**：第一次做歌、想要"像电台里播的那种歌"、做个人单曲 demo

```
一首中文城市治愈抒情歌。画面是深夜加完班独自打车回家，车窗外是下雨后的路灯，
情绪从疲惫沉默慢慢转向接受和释怀。华语流行为主，融入一点 R&B 的松弛感；
钢琴为主奏，副歌加入温暖的弦乐铺底。温柔女声，中低音区，带轻微气声，
咬字清晰不炫技不飙高音。BPM 82，中速抒情。
结构：主歌—预副歌—副歌—主歌2—副歌2—桥段—尾奏，时长约 3 分钟。
整体干净通透，人声清晰靠前，混响克制。不要电子炸裂编曲，不要 rap，不要过快节奏。
```

**逐条解释**

| 片段 | 作用 | 不写的后果 |
|---|---|---|
| 画面：深夜打车、雨后路灯 | 决定配色与环境感，模型会倾向湿润的混响与中慢速 | 只剩抽象情绪，编曲平淡无色彩 |
| 情绪从疲惫→释怀 | 给出动态曲线，副歌会更开阔 | 整首歌情绪一条直线，没有推进 |
| 华语流行 + R&B 松弛感 | 双标签组合，避免平庸 | 只有一个标签时容易生成"模板歌" |
| 钢琴为主，副歌加弦乐 | 控制配器与段落层次 | 配器随机，可能人声被盖住 |
| 温柔女声 + 气声 + 不炫技 | 锁定音色与演唱方式 | 出现撕裂高音或过亮音色，不符合"治愈" |
| BPM 82 | 锁定抒情速度区间 | 可能生成偏快，治愈感丢失 |
| 结构 + 3 分钟 | 控制副歌出现时机 | 副歌来得太晚，短视频用不了 |
| 三个"不要" | 排除跑偏方向 | 可能混入 rap 或电音段落 |

**预期效果**：钢琴引入 + 贴耳的低语式女声，主歌克制、预副歌有一个小渐强，副歌旋律上扬、弦乐托起；第二段加入轻鼓；桥段抽空只剩钢琴与人声；最后一遍副歌完整收束后渐弱。属于"戴着耳机在夜里听"的成品感，适合作为个人单曲 demo、情绪类短视频配乐。

**如果不满意**
- 副歌不够抓耳 → 加"副歌前留半拍空白，副歌第一句进入高音区，配一个短句重复 hook"
- 太慢太催眠 → BPM 提到 92，加"加入轻微律动感的鼓组"
- 人声发闷 → 加"人声明亮通透，减少低频掩蔽，混响干一些"

### 案例 1.2 古风国潮（中文优势场景）

**适用**：国风单曲、古装短视频、文旅宣传、汉服/非遗内容

```
一首国风流行歌曲。画面是深秋旧城巷口的一次告别，落叶与薄雾，情绪克制但遗憾很深。
古筝为主奏，配竹笛与少量二胡，副歌加入轻量的现代电子鼓，让古意里有都市感。
女声清亮温润，桥段加入一小段戏腔吟唱作为记忆点，不要全程戏腔。
BPM 92，中速偏舒缓。结构：主歌—副歌—主歌2—副歌2—戏腔桥段—副歌3—尾奏。
整体空灵有留白，不要乐器堆满，不要重金属吉他，不要合唱军鼓进行曲感。
```

**逐条解释**：乐器指定到"古筝 + 竹笛 + 二胡"是国风的核心信号；"副歌加入少量现代电子鼓"是国潮（而非纯古风）的关键差异化；"桥段一小段戏腔"指定位置，能避免出现得莫名其妙；"不要乐器堆满"在国风里非常重要——民乐一多就糊。

**预期效果**：古筝颗粒清晰的前奏，女声干净且有古典咬字感；副歌有明显的现代鼓点推动；桥段戏腔一出来就是记忆点。适合古装剪辑、汉服变装、文旅短片。

**变体**：换成"男生 + 唢呐 + 大鼓"即变成武侠影视感；换成"无鼓 + 箫 + 留白"即变成禅意空灵版。

### 案例 1.3 温柔民谣叙事

**适用**：个人故事、毕业、故乡、朋友圈向的原创歌

```
一首温暖治愈的中文民谣。木吉他分解和弦为主，副歌加入钢琴与轻轻的手鼓。
画面是大学毕业前最后一节课后，几个人在操场草地上坐着不说话。
男声质朴，像在耳边慢慢说一件事，嗓音有一点颗粒感，不要油腻不要飙高音。
BPM 96，结构：主歌—副歌—主歌2—副歌2—桥段—副歌3，第二段副歌加入和声伴唱。
整体像在一个小房间里录的，保留呼吸感，不要过度修音，不要电音感，不要鼓点过重。
```

**预期效果**：吉他先行、人声贴近，副歌出现明显的和声堆叠带来温度；制作上保留"不完美感"反而更真诚。

### 案例 1.4 慢摇说唱Melodic Rap（内心独白向）

**适用**：打工人叙事、剧情号、态度表达

```
一首中文慢摇说唱（melodic rap），主题是城市打工人的内心独白。
808 低频贝斯铺底，节奏舒缓，旋律性强的副歌 hook，verse 部分偏低沉叙述。
男声低沉带颗粒感，咬字清楚，情绪克制真实，不嘶吼不炸。
BPM 88，结构：verse—hook—verse2—hook—bridge—hook。
整体低频厚实但不轰头，人声在中间清晰。不要快嘴，不要 Trap 的密集 hi-hat，不要电音失真。
```

**预期效果**：verse 是半说半唱的低语，hook 有明确旋律记忆点；低频饱满适合戴耳机听。

## 模块 2 · 专业模式（自己带歌词，可控性最高）

> 专业模式的重点：**歌词必须分段写清楚**。建议使用下面的结构标记，模型才不会把副歌处理成主歌。

### 案例 2.1 带歌词的标准提交格式

```
[风格描述]
华语流行抒情，钢琴为主、弦乐托底，副歌加入鼓与和声堆叠，情绪由隐忍到释放；
女声温暖有力量，中音区为主，副歌可放开；BPM 84。整体干净、人声靠前。

[歌词]
[Verse 1]
...（4~8 句，句尾押同一韵，描写具体场景）
[Pre-Chorus]
...（2~4 句，句子变短，情绪往上推）
[Chorus]
...（4 句以内，短句，重复度高，全歌情绪最高点）
[Verse 2]
...（场景推进，避免复述）
[Chorus]
[Bridge]（可选）
...（2 句，换一个角度点题）
[Chorus]
[Outro]
...（渐弱，留一句余韵）
```

**为什么这样写**

| 做法 | 原因 |
|---|---|
| 风格描述与歌词分开 | 避免描述词混进歌词被唱出来 |
| 用 `[Verse]/[Pre-Chorus]/[Chorus]/[Bridge]` 标记 | 明确段落角色，模型才知道哪里该爆发 |
| 副歌控制在 4 句以内、句子短 | 短句重复 = 记忆点；长句副歌很难传唱 |
| 主歌写具体场景，副歌写抽象情绪 | 符合华语流行的经典写法，层次清楚 |
| 桥段换角度点题 | 避免第三遍副歌的重复疲劳 |

**预期效果**：副歌到达时间合理（约 45 秒左右），动态明显，成品结构接近可发行的 demo。

**常见坑**
- 歌词不加段落标记 → 通篇一个情绪，没有高潮
- 副歌句数太多、每句都很长 → 唱词拥挤、旋律没留白
- 描述里写了"男声"但歌词是第一人称女性视角 → 语义冲突，务必保持一致

## 模块 3 · AI 作词（单独只要歌词）

> 妙响的 AI 作词是按主题/情绪生成多版本歌词并支持对话式修改。**给作词的提示词要指定：主题、视角、段落结构、押韵方式、字数与句数的量级、禁忌。**

### 案例 3.1 主题抒情词

```
请写一首中文流行抒情歌的完整歌词。
主题：搬家时翻到旧物，想起一段没有说出口的告别。
视角：第一人称，女性视角，不说"分手""失恋"这类直白词，用具象物品（旧票根、毛衣、钥匙）承载情绪。
结构：[主歌1 8句]—[预副歌 4句]—[副歌 4句×2遍]—[主歌2 8句]—[副歌]—[桥段 2句]—[尾奏 2句]
押韵：主歌押 an 韵，副歌押 i 韵，韵脚自然不生硬。
要求：句子长短交错，避免全是同一字数；不要空洞的网络伤感词（如"放不下忘不掉的世界末日"），
不要出现具体人名地名。副歌歌词控制在每句 8~12 字，要容易唱、容易记。
```

**解释**：指定韵脚（an / i）能显著提升"像歌"的程度；限制每句字数能避免模型写成长散文；"用具象物品承载情绪"是把 AI 词从"空洞"拉到"有画面"的关键指令。

**预期效果**：拿到的是可直接粘贴进专业模式的分段歌词，且自带押韵与重复结构。

### 案例 3.2 对话式二次修改（生成后觉得不对，用这类指令改）

| 你想改什么 | 直接这样说 |
|---|---|
| 太抽象 | "第 2 段副歌太空了，改成有具体画面的描写，加入雨、车窗、路灯这三个意象" |
| 不押韵 | "主歌 4 句全部改成押 'ang' 韵，不要为了押韵造词" |
| 太长唱不下 | "把每句压到 10 字以内，删掉修饰语，保留动词和名词" |
| 太直白 | "把'我想你'这种直白表达替换成动作描写，不要出现'爱''思念''心痛'这类词" |
| 情绪不够狠 | "最后一桥段改成更决绝的语气，用短句，每句不超过 6 字" |

## 模块 4 · 纯音乐 / 短视频 BGM（无人声）

> 纯音乐提示词的三个必须项：**用途场景 + 时长 loop 设计 + 起伏/卡点位置**。一定要写"无人声"。

### 案例 4.1 有起伏的转场配乐（卡到剪刀点上）

```
一段有起伏的氛围配乐，纯音乐无人声，用于短视频剪辑转场。
前半段安静悬停：只有合成器 pad 与微弱钢琴，情绪压着；
中段缓慢向上推进，加入弦乐与心跳般的低频；
第 12 秒左右出现一个很轻但清晰的鼓点重音作为转场卡点，
之后立刻展开成宽阔明亮的情绪，30 秒左右自然收尾。
整体干净、低频不轰、不抢画面和人声。时长约 30 秒，适合循环。
```

**解释**：把**时间轴**写进提示词（"第 12 秒一个轻鼓点"）是这个类型最强的技巧——用户往往需要在固定时间点上有一个 hit。

**预期效果**：前松后紧的呼吸感，第 12 秒有一个可对齐剪点的重音，非常适合慢镜头转特写的那一下。

**变体**：把"重音"换成"上升 riser + 落点"，适合时间线跳转类转场。

### 案例 4.2 日常 vlog 轻快 BGM

```
一段轻快治愈的纯音乐，适合日常/生活记录类 vlog，无人声。
木吉他拨弦 + 马林巴/钟琴为主，配轻巧的手拍节奏与口哨旋律，
明亮温暖，像周末早晨的阳光。BPM 112，稳定律动，情绪平和不上扬不过度煽情。
结构：简单循环 loop，每 8 小节一个小变化，总时长约 60 秒，可无缝循环。
整体动态平缓，作为背景不抢画面；不要明显的 drop，不要突然的音量变化。
```

**预期效果**：可以一直铺在整条视频下面不刺耳；8 小节一次的小变化避免听腻。

### 案例 4.3 高级松弛感质感铺底

```
一段高级松弛感的纯音乐，用于质感内容铺底/品牌短片背景，无人声。
极简配器：电钢琴 Rhodes 和弦 + 干净贝斯 + 刷子鼓，留白多，
带轻微黑胶噪声与模拟温暖的低频。BPM 92，Jazz/Neo Soul 质感，克制不炫技。
整体通透有空气感，动态平缓，不要铜管齐奏，不要明显旋律钩子，不要 Trap 鼓。
```

**预期效果**：像是咖啡馆/买手店会放的音乐，高级但不抢戏，适合访谈、产品展示、播客片头。

## 模块 5 · 音乐改编（翻唱 / 仿写 / 续写）

### 案例 5.1 翻唱（换歌词或换音色）

```
[使用方式] 进入音乐改编的翻唱模式，上传原曲或使用已有作品。

[改写要求]
保留原曲旋律与编曲框架，把人声换成年纪更轻的少年感男声，音色干净带一点点奶感；
减少原曲的混响，让声音更贴近耳边；整体速度放慢 6%（更沉一点）；
不需要改歌词时保持歌词不变。
```

**解释**：翻唱模式的核心是**明确"动什么、不动什么"**——只说"改成更好听"会让整首都变掉。指定"放慢 6%"、"减少混响"这类微调，效果最可控。

### 案例 5.2 仿写（照着参考曲做原创）

```
[使用方式] 进入仿写模式，上传参考曲，然后填写下面的风格描述。

请基于参考曲生成一首原创作品（仅借鉴风格，不要复制旋律）。
参考曲特征：慵懒的中文 R&B，中慢速，电钢和弦铺底，柔和轻 808，假音转音多。
我想要的成品：同样的慵懒质感，但把主题改成"清晨五点醒来的城市"，
情绪更明亮一点，副歌加入一层女声和声。女声慵懒带气声，BPM 由参考曲的 72 提到 84。
结构：主歌—副歌—主歌2—副歌2—桥段，时长约 2 分 30 秒。
```

**解释**：仿写模式的提示词要**先描述参考曲的关键特征（帮助稳定输出），再写差异点**（这是"仿"而不是"抄"的边界）。

### 案例 5.3 续写（在原曲基础上往下写）

```
[使用方式] 进入续写模式，选择要延伸的作品。

从原曲结尾的情绪继续往后延伸 40 秒：
保持原有的钢琴与弦乐音色，人声（女声）延续同样的质感，
先安静收束到几乎只剩呼吸与钢琴，再缓缓重新升起，形成第二个小高潮后淡出，
适合被用作视频的片尾。不要引入新的乐器，不要加快速度。
```

**解释**：续写最容易翻车的点是突然换配器/提速。明确"不要引入新乐器、不要加速"能大幅提升衔接自然度。

## 模块 6 · 虚拟歌手 / 人声替换

```
把当前作品的人声替换为：成熟温暖的女中音，咬字清晰，中音区厚实，
副歌有力量但不撕裂，保留原有的呼吸感；不要过度 AutoTune 的电音感。
人声与伴奏比例调整为 6:4，人声更靠前。
```

**适用**：生成后发现"歌好听但声音不对"，直接换虚拟歌手 + 微调比例，比重整首歌省时间。

**预期效果**：伴奏与旋律完全保留，只换嗓。建议在 AI 编辑器里再补一点混响与轻微压缩让声音更贴。

## 模块 7 · AI MV（给作品配画面）

```
为一首深夜城市治愈抒情歌生成 MV 画面。
风格：电影感的写实影像，蓝橙色夜景，浅景深，轻微手持晃动感；
固定出现的一男一女不必出现，聚焦一个独自走路的年轻人的背影与局部特写
（手指、鞋、车窗反射的脸）。
镜头：缓慢的推轨与延时摄影穿插，每 3~5 秒一切，跟随音乐起伏，
副歌时切到高空俯拍的城市夜景。
氛围：潮湿、安静、有一点胶片颗粒；不要出现文字字幕，不要卡通/二次元动漫风格，不要快速闪白。
```

**解释**：MV 提示词三要素：**影像风格 + 镜头语言 + 禁忌**。写清楚"不要"能避免出现廉价素材感。

## 模块 8 · 特殊商业场景速查

| 用途 | 直接可用的一句话提示词 | 关键控制点 |
|---|---|---|

## 模块 9 · 批量生产（做账号矩阵/系列 BGM）

思路：**固定住"母提示词"，每次只改 1~2 个变量**，保证系列统一又有差异。

```
母提示词：一段轻快治愈的纯音乐，木吉他 + 马林巴 + 轻拍手，BPM 112，明亮温暖，
动态平缓不抢画面，无人声，60 秒可循环，共 5 个版本，分别适配：

版本1 早晨咖啡：加口哨旋律、更明亮
版本2 通勤路上：加入稳定低音贝斯、律动更明显
版本3 做饭日常：加入轻爵士和弦、更松弛
版本4 收纳整理：去掉低音、更干净留白
版本5 结尾卡片：加入简单的弦乐上扬、收尾更开阔
```

**预期效果**：一次性拿到主题统一、可直接配到一组视频里的成套 BGM，账号内容听起来有"品牌感"。
