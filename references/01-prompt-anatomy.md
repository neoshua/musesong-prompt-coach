# 提示词解剖：把"好听"翻译成模型听得懂的话

## 一、为什么你的提示词没效果

模型不是人，它理解不了"好听""高级感""有感觉"。它只能从**可量化的音乐要素**（曲风、乐器、速度、结构、人声描述词）和**可感知的画面意象**（雨夜、路灯、海边清晨）里找对应关系。

| 用户写的 | 模型听到的 | 应该改成 |
|---|---|---|
| 好听的歌 | （无有效信号） | 华语抒情流行，钢琴为主，副歌旋律上扬 |
| 高级感 | （微弱，偏向电子/爵士） | 极简配器、留白多、弦乐铺底、混响克制、不堆音色 |
| 有感觉 | （无有效信号） | 具体画面 + 情绪走向：深夜独自行驶，情绪从疲惫到释怀 |
| 伤感但不要太伤感 | （矛盾信号） | 小调色彩但编曲干净，人声克制不哭腔，副歌不做撕心裂肺的爆发 |
| 专业的 | （无音乐含义，容易堆砌技巧） | 编曲层次丰富、鼓组清晰、副歌加入和声堆叠、尾奏渐弱 |

## 二、九要素清单与权重排序

**权重顺序（越靠前越重要）**：

| # | 要素 | 必须？ | 常用写法 | 说明 |
|---|---|---|---|---|
| 1 | **作品类型/用途** | ✅ | 一首中文流行抒情歌 / 一段短视频纯音乐 BGM / 播客片尾配乐 | 决定模型是按"歌曲"还是"配乐"组织内容 |
| 2 | **场景画面 + 情绪走向** | ✅ | 深夜加班后独自打车回家，情绪从疲惫转到释怀 | 最强的一级变量，决定编曲密度与动态 |
| 3 | **主曲风 + 融合元素** | ✅ | 华语流行为主，融入 R&B 转音；国风为主，副歌加轻量电子鼓 | 单一标签容易平庸，两个标签组合才有辨识度 |
| 4 | **主奏乐器 / 音色** | 推荐 | 钢琴为主、木吉他分解和弦、古筝 + 竹笛、808 鼓 + 合成器 Pad | 直接决定听感质地，比风格名词更有效 |
| 5 | **人声性别与质感** | 带人声必填 | 温柔女声，带轻微气声，中低音区，不炫技 | 不写会得到"平均音色"，常常不对味 |
| 6 | **节奏与速度（BPM）** | 推荐 | BPM 82，中速抒情；或写"中速、有轻微律动感" | 不确定速度时写体感描述也有效 |
| 7 | **段落结构与时长** | 推荐 | 主歌—预副歌—副歌—桥段—副歌，时长约 3 分钟 | 短视频用简化结构，能避免"副歌来太晚" |
| 8 | **制作质感 / 参考系** | 进阶 | 干净通透、人声清晰靠前、混响克制；接近电台情歌质感 | 控制"成品感"，减少 demo 味 |
| 9 | **负向约束（不要什么）** | 进阶但很有效 | 不要电子炸裂编曲，不要 rap，不要过度修音的电音感 | 排除项能显著减少跑偏，尤其写给专业创作者/纯音乐 |

**经验值**：新手写出要素 1~5 就能得到 70 分的结果；补齐 6~9 通常能把"能听"提到"能发"。

## 三、五个让效果翻倍的写法

### 1. 画面锚点法（最推荐）
用**一个具体的时空场景**替代形容词，模型会自动推导出配器、速度、动态。

> 模板：`[时间] + [地点/环境] + [人物状态] + [情绪变化]`
> 例："凌晨四点，天快亮没亮，一个人坐在搬家后空荡荡的客厅地板上，先是茫然，然后慢慢接受"

### 2. 通感描写（颜色/温度/质地）
> "清透的夜色感"、"暖橘色的午后"、"潮湿的、带水汽的声音"、"毛玻璃一样模糊的 pad"、"像被太阳晒过的棉布一样松弛"

这些词能影响混响、音色亮度、编曲密度，是最容易被忽视的调味剂。

### 3. 动态曲线（让歌有起伏，不平）
> "主歌几乎只有钢琴和人声，副歌加入弦乐与鼓，桥段突然抽空只剩人声和呼吸，最后一遍副歌全乐器齐奏"

**这是区分"demo"和"成品"的关键写法。** 没有动态的歌听起来像在原地踏步。

### 4. 记忆点指令（给副歌一个钩子）
> "副歌前留半拍空白"、"副歌第一句用高音区进入"、"副歌有重复洗脑的短句 hook"、"第二遍副歌加入合唱堆叠"

⚠️ 只写"副歌要抓耳"是不够的：模型会把同一动机每次都即兴变奏，听众仍然记不住。**必须同时写出"形式 + 位置 + 重复次数 + 保持完全一致"**，详见 `07-hook-design.md`（本技能最关键的章节之一）。

### 5. 负向约束（排除比堆砌更有效）
> 常见排除项：不要 rap / 不要金属失真吉他 / 不要过多的电子音效堆砌 / 不要过度 AutoTune 电音感 / 不要突然的音量爆音 / 不要拖沓的尾奏 / 不要粤语发音 / 不要童声

⚠️ 注意：**不要写超过 5 个排除项**，太多会互相干扰。也不要用"不要不好听"这种无信息量的否定。

## 四、长度与信息密度

- 灵感模式：**60~120 字**最佳。太短信息不足，太长（>250 字）后面的要素会被稀释。
- 专业模式：风格描述控制在 **80~150 字**，主要信息交给歌词段落和界面上的参数选项。
- **重复关键要素 2 次**可以提高其权重（如在开头写"慢速"，结尾再写"整体偏慢、不要提速"）。

## 五、两种模式的写法差异

| | 灵感模式 | 专业模式 |
|---|---|---|
| 输入形态 | 一句话复合描述 | 风格描述 + 自写歌词 + 界面参数（曲风标签/速度/调式等） |
| 提示词重点 | 场景 + 情绪 + 曲风 + 人声，四要素齐全即可 | 歌词结构必须写清楚（主歌/预副歌/副歌/桥段），描述用来控制编曲 |
| 什么时候用 | 还没想清楚、想多版本对比、给短视频找音 | 已有歌词或明确动机、需要可控结果 |
| 常见坑 | 只写"一首伤感的歌"，结果平庸 | 歌词不分段落，模型把副歌唱成主歌，没有爆发 |

**推荐路径**：先用灵感模式出 2~4 版，挑出接近的方向，再切专业模式锁定歌词与参数——这是投入产出比最高的工作流。

## 六、可以叠加的"专业参数"措辞

界面上如果有对应选项就优先用选项（更准）；没有时，把下面这些写进描述里作为软约束：

- 速度：`BPM 78`（慢）/ `BPM 96`（中速律动）/ `BPM 128`（舞曲）
- 拍号：`4/4 拍`（默认）/ `6/8 拍`（摇曳感，适合抒情 ballad）
- 调性色彩：`大调，明亮温暖` / `小调，克制内敛` / `副歌转大调（色彩突然开阔）`
- 人声位置：`人声稍微靠前，伴奏退后` / `人声与乐器平衡`
- 混响：`混响克制，接近干声` / `空旷大厅感混响`
- 制作要求：`动态平缓，适合作为背景不抢画面` / `起伏明显，适合卡点`

> 若平台当前版本未提供某选项，写在描述里依然会被部分理解；若完全无效，就退回到体感描述（"偏慢一点"、"更像现场"）。
