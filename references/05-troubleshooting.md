# 效果诊断与迭代：从"能听"到"能发"

> 用法：用户反馈"不好听/不对/怪怪的"时，先把模糊抱怨翻译成右表中的**具体症状**，再对症改。一次只改 1~2 个变量，否则无法判断是哪一项起了作用。

## 一、症状 → 病因 → 处方

| 症状 | 最可能的原因 | 立刻这样改 |
|---|---|---|
| 副歌不抓耳、听过就忘 | 主歌副歌情绪一样平，没有动态 | 加"主歌只留钢琴与人声，副歌加入鼓与弦乐，副歌前留半拍空白"；副歌每句压到 8~12 字并重复一句 hook |
| **整体平庸、听完就忘（最常见）** | **没有 hook，或 hook 被模型每次变奏掉了** | 走 `07-hook-design.md`：指定一个 3~5 音的动机 + 前 3~15 秒首次出现 + "重复不少于 4 次、保持完全一致、不要每次都变奏" |
| hook 出现太晚，观众已划走 | 没指定位置 | 加"前 3 秒由它独奏开场"、"每 8 小节出现一次" |
| 整首歌像在原地踏步 | 缺动态曲线 | 写动态指令："主歌极简 → 副歌全奏 → 桥段抽空只留人声 → 最后一遍副歌齐奏" |
| 人声发闷、糊、听不清词 | 伴奏太厚、低频打架 | 加"人声清晰靠前，减少低频掩蔽，混响克制"；或进 AI 编辑器做音轨分离后压低伴奏、给干声加轻微降噪与去齿音 |
| 人声太亮/太刺/电音感重 | AutoTune 或音色过亮 | 提示词加"保留自然呼吸感，不要过度修音的电音感"；编辑器里降低修音强度 |
| 曲风跑偏（要抒情结果成 disco） | 描述里混入冲突词 | 删掉无关词，只保留 1 个主风格 + 1 个融合元素；把核心风格写到句子最前面 |
| 太快/太慢 | 速度感没锁定 | 卡点/舞曲类给 BPM 数字（抒情 76~88 / 律动 92~104 / 明快 110~124 / 电子 126~140）；**写词/抒情类官方不建议硬写 BPM**（`WNB:124`「强行设定会让歌词听起来特别赶」），改用「舒缓、有律动」等体感词 |
| 副歌来太晚，短视频用不上 | 结构太长 | 写"30 秒内进入副歌，主歌缩短到 4 句，总时长 60~90 秒" |
| 配器太吵/太满 | 没控制密度 | 加"极简配器、留白多、不要乐器堆满"；民乐混合时尤其要写这句 |
| 伴奏盖过人声（尤其国风/Electronic） | 没有指定声压关系 | 加"人声与伴奏比例约为 6:4，人声为主" |
| 中文咬字怪、平仄错位 | 倒字或字数不对称 | 用中文写风格提示词（`MVeB:103` 中文咬字更准）；上下句字数与重音对齐（`EWzn:319-321`）；多音字用同音字替换后重生成（见 2.1） |
| 歌词里有英文/奇怪词汇被唱出来 | 描述词混进了歌词区 | 专业模式下把风格描述与歌词严格分开，歌词区只放歌词 |
| 尾奏拖沓、突然截断 | 没指定收尾 | 加"尾奏渐弱自然收束，约 8 秒"或"结尾干净利落收在一个和弦上" |
| 有多个版本都很平庸 | 提示词太泛 | 加一个**具体画面锚点**和一个**反差元素**（如"民谣 + 电子鼓"） |
| 改了很多轮反而越改越差 | 反复点“重新生成”，每次都是新的随机抽样，好的版本被丢掉了 | 停止重生成：锁定一版母版，用片段重写 / 换虚拟歌手 / AI 编辑器做局部微调（见 `08-advanced-techniques.md` 技巧 4） |
| 中文唱出来像另一个字 | 倒字 / 多音字 / 粤语串台 | 官方三修法见 2.1；另可换声调不同的同义词、句尾改平声、只重写那一小段（`08` 技巧 3） |
| 某个重音对不上视频画面 | BPM 与剪点没换算 | 用 `BPM = 240×N ÷ T` 反推，或在编辑器里把那一小段音频拖动 0.1–0.2 秒（`08` 技巧 1） |
| **歌词像硬套上去的、像念稿、字挤在一起** | 字数与音符数不匹配 / 标点没给停顿 / 缺韵脚 | 先按官方：`EWzn:319-321` 上下句字数与重音一致、用 `，！？。` 造停顿、`Jdxf` 押韵体系；本技能急救建议（单句 8-12 字、句长统一、实词收尾）见 `09-lyrics-melody-alignment.md`——**这些是经验值不是官方硬规则**；严重时用两阶段法 |
| 旋律好听但词怎么改都别扭 | 模型先生成唱腔再贴词 | 就该旋律不再改词，只砍字留白；或用**音乐改编·翻唱**保曲改词（参考音频权重 8-9，见 2.1） |

## 二、模型与迭代（v2.0 按官方核实修正）

**官方模型清单**：音乐生成只有 **Sway v5.0 / v5.5**；AI MV 视频模型是 **Seedance 2.0 / 2.5**。旧版写的 `SeedMusic`、`Mureka`、`Sodance` 在官方 32 篇文档里**全库无据**（`Sodance` 应为 Seedance 拼写错误），已删除；Suno / Chirp 只出现在知识库收录的**第三方**材料里，不是妙响模型。

→ 因为可选底座很少，「换模型」不再是万能解法。**官方推荐的迭代顺序**是：

| 优先级 | 做法 | 官方依据 |
|---|---|---|
| 1 | **只改 3-5 个词**，不要完全重写提示词 | `FKQK:389` |
| 2 | 一次生成**两个版本**：一版差异大、一版保留原曲基调；不原地覆盖历史版本 | `Bu2:200`、`Dkd:27` |
| 3 | **音乐改编 / 翻唱**做局部重写（改词不改曲、片段重写），参考音频权重 8-9、风格权重与创意发散尽量低 | `Jqx:52-93`、`Bu2:58` |
| 4 | 压短提示词（30-60 词）、删掉冲突情绪词，再换 Sway v5.0 ↔ v5.5 跑同一条 | `FKQK:262/386` |
| 5 | 最后才考虑 AI 编辑器精修（音轨分离、变速变调、智能母带） | `AaL9`、`BKF` |

> 具体模型名与界面选项以妙响当前页面为准；本表按 2026-11-04 官方知识库核实。

### 2.1 中文唱错字 / 咬字 / 串粤语（官方三修法，`Jqx` 全篇）

| 修法 | 操作 | 关键点 |
|---|---|---|
| ① 同音字替换 | 把「稀」换成「西」或「细」，**只改编歌词，其他的不动，重新生成** | 「音调不一样没关系，不影响唱出来的效果」（`Jqx:36-44`） |
| ② **音乐改编·翻唱**（官方推荐 👍） | 改词不改曲，对**单个字**精准修改；风格描述「R&B、流行」即可，也可不填 | 参考音频权重 **8-9**、风格权重与创意发散**尽量低**（`Jqx:91`）；「太复杂的提示词会起到反效果」（`Jqx:89`） |
| ③ 音色替换 / 智能演唱 | 只换嗓音 | ⚠️「**这种做法并不能实现更改错字的效果**」（`Jqx:99-131`），别走错路 |

补充：`MVeB:103`「用中文提示词生成的歌曲中文咬字更准确哦」；`EWzn:333` 粤语串台用同音词替换；`JauM:308` 保韵改词指令「保留原本的韵脚将 xxxx 改为符合人类日常表达的字眼」。详见 `12-official-guide.md` 第六节。

## 三、AI 编辑器精修（提示词的"下半场"）

生成够好之后，用这些手段把 demo 推到"可发布"：

| 步骤 | 做什么 | 什么时候需要 |
|---|---|---|
| 音轨分离 | 拆成人声 / 干声 / 和声 / 伴奏 | 要调整比例、做无人声版本、或导出纯伴奏 |
| 段落精修 | 只重写不满意的某一段（如第二主歌） | 局部不合格，不想重做整首 |
| 虚拟歌手替换 | 保留伴奏与旋律，换嗓 | 歌好但声音不对 |
| AI 和声设计 | 给副歌加和声堆叠 | 副歌单薄、不够厚 |
| 降噪 / 去齿音 | 清理口齿音与底噪 | 人声有滋滋声、环境噪声 |
| 变速 / 变调 | 整体提速或升降 Key | 想要适配不同视频节奏/歌手音域 |
| AutoTune | 修音，注意控制强度 | 旋律跑调，但要保留呼吸感 |
| 混响与母带导出 | 智能母带 / 智能混音母带 / 轨道合并 | **发行前的最后一步** |

**建议发行前的最低处理**：导出纯伴奏 + 干净人声各一份备用；做一次智能母带让响度达到平台水平；戴耳机检查 0:00–0:05 是否有爆音、结尾是否拖沓。

## 四、二次创作与发行提醒

- **做同款**：作品区看到喜欢的歌可以用"做同款"起步，比从零写提示词省事。
- **发行**：成品可提交发行至汽水音乐并同步抖音曲库，版权与收益归创作者；提交前务必确认封面（可用智能封面生成）、歌名、歌词无错别字。
- **商用**：自生成的原创音乐用于视频配乐一般没问题，但若**翻唱/仿写他人作品**（音乐改编的翻唱与仿写模式），须注意不要直接复制原曲旋律与歌词，商业化前确认授权。
- **系列化**：同一账号建议固定"母提示词 + 变量"，形成统一听觉品牌（批量做法见 `03-case-library.md` 模块 9）；若要做**同一主题的多首作品**（如地方文旅的纯音乐 + 歌曲双版本），用 `07-hook-design.md` 第十一节的三固定：签名音色、同一个动机、同一套参数语言。

## 五、给用户的一轮标准复盘话术

> 生成结果出来后别急着重写整首。挑最接近的那版，告诉我：**①哪里不对**（副歌/人声/速度/配器）**②想要的参照**（像哪首歌的感觉）。
> 一次改 1~2 个点（官方建议**只改 3-5 个词**，`FKQK:389`），通常 2~3 轮就能到可以用的水平；如果还不顺，我会帮你用音乐改编·翻唱做局部重写，或换 Sway 版本重跑。
