# 曲风 / 乐器 / 人声 / 质感词库（可直接挑词填空）

用法：每个类别**挑 1~2 个**组合使用。挑得越多不等于越好，堆砌会让模型失去重点。

## 二、乐器与音色词（挑 2~3 个）

**键盘/弦乐**：钢琴、电钢琴（Rhodes）、三角钢琴、弦乐群奏、弦乐四重奏、竖琴、钟琴（Glockenspiel）、 music box 音乐盒
**拨弦**：木吉他（分解和弦 / 扫弦）、尼龙弦吉他、电吉他（清音 / 轻过载 / 失真）、贝斯（拨弦 / slap / 808 低音）、尤克里里、班卓、曼陀林
**民乐**：古筝、二胡、琵琶、竹笛/箫、埙、尺八、笙、葫芦丝、扬琴、唢呐（慎用，存在感极强）、编钟、木鱼/梆子
**管乐/铜管**：小号、萨克斯、长笛、单簧管、铜管组（Funk/复古常用）
**打击**：架子鼓（原声 / 紧凑）、电子鼓机、808 鼓、tr808 hi-hat、手鼓、木箱鼓（Cajon）、沙锤、铃鼓、大鼓（武侠）、非洲鼓、三角铁
**合成器**：Analog Pad、Pluck、Lead 主音、Arp 琶音、Sub Bass、白噪声 riser、低保真 keys、chiptune 芯片音
**环境/特殊**：黑胶噪声、雨声、环境采样、地铁报站采样、呼吸声、合唱 Pad

> 小技巧：说"**以 X 为主，Y 为辅**"比罗列一串乐器更有效；再加一句"配器简洁 / 编曲层次丰富"控制密度。

## 三、人声描述词（决定"像谁在唱"）

**性别与人数**：男声 / 女声 / 男女对唱 / 男声合唱 / 女声和声 / 童声 / 群合唱

**质感**：清亮通透 · 温暖醇厚 · 沙哑颗粒感 · 气声（耳语感） · 少年感/奶音 · 烟嗓 · 甜美 · 空灵仙气 · 慵懒低沉 · 力量爆发嗓 · 说念穿插

**情绪表达**：克制内敛 · 轻声诉说 · 哭腔（慎用） · 坚定有力 · 自由转音 · 假音/真音切换 · 咬字清晰

**距离与空间**：贴近耳边/ASMR 感 · 人声靠前伴奏退后 · 空间感大混响 · 干声干净

**组合模板**：
`[性别] + [质感1] + [质感2] + [表达] + [附加限制]`
> 例：温柔女声，中低音区，带轻微气声与沙哑颗粒，咬字清晰，副歌不做撕裂爆发，不要过度修音的电音感

## 四、制作质感词（控制"成品感"）

干净通透 · 空气感 · 湿润 · 温暖模拟味（analog warmth） · 低保真 Lo-fi · 黑胶质感 · 电影感 · 现场录音感 · 极简留白 · 层次分明 · 低频饱满 · 人声明亮 · 母带级响度 · 无过度压缩

## 五、情绪/画面词（用于给画面锚点）

**时间**：清晨微光、午后斜阳、黄昏、日落后蓝调时刻、深夜、凌晨四点、下雨的傍晚
**空间**：空房间、便利店门口、地铁末班、海边、山雾、旧巷、天台、车里、操场、便利店、雪地
**状态**：独自走路、搬家整理、翻旧照片、等一个人的消息、辞职后的第一周、毕业前的最后一节课
**质地/颜色形容**：清透、潮湿、温热、毛玻璃感、橘色暖光、蓝调忧郁、干净的白、旧胶片色

## 六、万能替换：一句话套用

```
一首[主曲风]，[融合元素]点缀；画面是[时间+地点+人物状态]，情绪[起始]到[结束]；
[主乐器]为主、[辅助乐器]为辅；[人声描述]；约 [BPM] 的速度，[结构]；
整体[质感词]，[需要在哪爆发/留白]；不要[排除项]。
```
