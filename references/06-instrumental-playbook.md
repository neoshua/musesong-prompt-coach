# 纯音乐（无人声）提示词专章

> 适用于：短视频 BGM、vlog 配乐、播客片头片尾、转场配乐、开场 sting、品牌/企业短片、延时摄影与航拍、纪录片空镜、游戏场景 loop、活动暖场、冥想专注。
> 一句话区别：**有歌词的歌靠"歌词 + 人声"传意；纯音乐只能靠"音色 + 情绪曲线 + 时间轴"传意。**所以纯音乐的提示词要把这几项写得更细。

---

## 一、首先：必须先把人声关掉（最容易翻车的一步）

AI 音乐模型默认倾向"生成一首完整的歌"，所以纯音乐提示词**必须显式写死无人声**。建议在提示词开头第一句就写：

```
纯音乐，无人声，不要人声演唱，不要哼唱、口哨、 vocal chop、合唱垫人声，全部由乐器演奏。
```

**推荐写法**（三重保险）：
1. 开头写 `纯音乐 / instrumental only`
2. 中间写 `无人声`
3. 结尾的"不要"里再写一次 `不要人声、不要哼唱`

如果还是生成了人声别急着重写：**进 AI 编辑器做音轨分离，直接删掉人声轨 / 只导出伴奏轨**，通常比重新生成更快。

## 二、纯音乐五步法（替代 SKILL.md 里的七步）

| 步 | 要定的东西 | 给用户的问法 |
|---|---|---|
| ① | **用途**：铺全程 / 转场 / 开场 / 片尾 / 循环背景 | "这段音乐是全片垫着，还是只在某一秒出现一下？" |
| ② | **时长与节奏点**：15s / 30s / 60s / 90s，卡点在第几秒 | "你希望视频第几秒出现那个'咚'？" |
| ③ | **情绪曲线**：平铺 / 渐强 / 起伏 / 先抑后扬 / 收束 | "从头到尾情绪是平的，还是要起来一下？" |
| ④ | **乐器编组**：主奏 + 支撑 + 点缀三层各是什么 | "想要钢琴感、吉他感、还是弦乐/电子那种？" |
| ⑤ | **频段与空间**：低频厚度、是否要给人声留位置、混响干湿 | "视频里有人说话吗？"（有说话 → 必须避让人声频段） |

## 三、六个决定成败的写法

### 1. 时间轴标注法（纯音乐的第一技巧）
把**秒数**直接写进提示词，模型会照着安排事件。这是纯音乐比歌曲更容易做到"精准"的地方。

```
0–6 秒：只有钢琴单音，安静
6–12 秒：加入弦乐垫底，情绪缓慢上升
12 秒：一个清晰的低频落点（hit），画面在此转场
12–25 秒：鼓组进入，情绪展开变明亮
25–30 秒：渐弱收尾
```

### 2. 三层配器法（比堆乐器名有效）
```
主奏层（旋律）：钢琴 / 吉他 / 竹笛 / 合成器 lead
支撑层（和声与低频）：弦乐垫、Pad、贝斯
点缀层（色彩）：钟琴、铃鼓、口哨、沙锤、黑胶噪声
```
**每条提示词只要写清楚这三层，音色就不会乱。** 别一次性列十个乐器，声音会糊。

### 3. 频段避让（旁白视频必写）
视频里有人说话时，要在提示词里要求"让位"：
> `旋律密度低，中频（人声区）留白，不要密集的琶音与高频撞击，整体退后 6dB，不抢台词`

反之无人说话的纯画面可以更满：
> `低频饱满，有推进感，可以适当堆层次`

### 4. 循环设计（loop 类必写）
```
总时长 30 秒，可无缝循环（首尾音量与和声对齐，不要明显的开始与结尾），
每 8 小节出现一次小变化避免听腻
```
没写这句，生成的音乐往往有明显前奏和收尾，循环时会"咔一下"。

### 5. 动态控制（决定能不能当背景）
- 背景垫底用：`动态平缓，音量起伏小，没有明显的 drop 与突然的强音`
- 转场/卡点用：`有明显的推进与落点，第 X 秒出现重音`
- 开场用：`0–3 秒快速上升的 riser，落在第 4 秒`

### 6. 排除清单（纯音乐专用）
`不要人声 / 不要哼唱 / 不要口哨（除非特意要） / 不要明显的旋律钩子（背景用） / 不要突然的音量变化 / 不要低频轰头 / 不要爵士鼓独奏炫技 / 不要过长的尾奏`

## 四、场景案例库（每条都可直接粘贴）

### 案例 P1 · 慢镜转场（最常见的刚需）
```
纯音乐，无人声。一段用于短视频转场的有起伏氛围配乐。
前三秒安静悬停，只有合成器 pad 与微弱钢琴单音；
中段缓慢推进，加入弦乐与心跳般的低频脉冲；
第 12 秒出现一个很轻但清晰的鼓点重音，作为剪辑卡点；
落点之后立刻展开成开阔明亮的情绪，最后 5 秒渐弱收束。
时长约 30 秒，整体干净通透，低频不轰头，不抢画面。
不要人声、不要哼唱、不要突然的音量爆音。
```
**为什么这样写**：纯音乐转场只需要"压住—推上去—落一下—放开"四件事，用秒数写死，模型几乎不会跑偏。
**效果**：前松后紧的呼吸感，第 12 秒一个可对齐剪刀点的重音。适合慢镜俯拍转特写、产品揭开、时间线跳转。
**变体**：要"时间跳转"感就换成 `第 12 秒改为上升 riser + 白噪声推进，落到第 13 秒的重音`。

### 案例 P2 · 日常 vlog（全程垫底，最耐听）
```
纯音乐，无人声。一段轻快治愈的日常 vlog 背景音乐。
木吉他拨弦为主奏，配马林巴（钟琴）与轻巧的手拍节奏，间或一句口哨旋律。
明亮温暖，像周末早晨的阳光，情绪平和不上扬也不煽情。
BPM 112，稳定律动。结构为简单循环：每 8 小节加一个小变化，总时长 60 秒，可无缝循环。
动态平缓，作为背景不抢画面；不要明显的 drop，不要突然的音量变化，不要人声。
```
**效果**：可以一路铺满整条视频不刺耳，8 秒一次的小变化避免听腻。适合生活记录、开箱、做饭、收纳。

### 案例 P3 · 高级松弛质感铺底（访谈/产品/播客片头）
```
纯音乐，无人声。一段高级松弛感的品牌短片背景音乐。
极简配器：电钢琴 Rhodes 和弦 + 干净贝斯 + 刷子鼓，留白多。
带轻微黑胶噪声与模拟温暖的低频，Jazz / Neo Soul 质感，克制不炫技。
BPM 92，动态平缓，旋律密度低，中频留白不抢台词。
不要铜管齐奏，不要明显的旋律钩子，不要 Trap 鼓，不要人声。
```
**效果**：买手店、咖啡馆会放的音乐，高级但不抢戏。适合访谈画面、产品展示、播客片头。

### 案例 P4 · 空镜 / 延时摄影 / 航拍（Cinematic Ambient）
```
纯音乐，无人声。一段电影感的纪录片空镜配乐，用于延时摄影与航拍大景。
以缓慢的合成器 pad 铺底，叠加钢琴单音与弦乐群奏，无鼓或仅有极轻的低频脉冲。
情绪从沉静到宏大：0–20 秒保持安静留白，20–40 秒弦乐逐渐增厚，
40–50 秒达到开阔的高点后缓缓收束。整体空旷、湿润、有大空间混响。
低频干净不轰，动态舒展；不要强节奏，不要流行鼓点，不要电子 drop，不要人声。
```
**效果**：那种"镜头慢慢拉远、看得起鸡皮疙瘩"的电影配乐感。适合延时、航拍、情感类空镜。

### 案例 P5 · 学习 / 专注背景（无动态）
```
纯音乐，无人声。一段极简安静的钢琴 Loop，用于学习与专注场景。
只有钢琴与自然的环境留白，极少的弦乐垫底，无鼓点。
BPM 64，几乎无动态变化，无高潮无转折，和声循环平缓，
可以长时间连续播放不腻。旋律密度低，音量起伏小于 3dB。
不要打击乐，不要转调，不要突然的强音，不要人声。
```
**效果**：占注意力极低，适合写字、读书、陪学习直播。关键是"**不要变化**"——大多数 AI 默认会制造起伏，这里必须压住。

### 案例 P6 · 播客三件套（片头 / 转场 sting / 片尾）

**片头（8–15 秒）**
```
纯音乐，无人声。一段 10 秒的播客片头音乐。
温暖轻盈，吉他分解和弦 + 轻贝斯 + 刷子鼓，第 6 秒有一次小的和声上扬，
最后 1 秒自然收在一个干净的和弦上，方便接人声。
明亮、亲切、口语感强；不要厚重、不要电影感、不要人声。
```

**章节转场 sting（3–5 秒）**
```
纯音乐，无人声。一段 4 秒的转场音效型音乐：
两个和弦加一声清脆的钟琴，短促干净，有明确的开始与结束。
不要渐强过程，不要尾韵拖长，不要人声。
```

**片尾（30–60 秒）**
```
纯音乐，无人声。一段温暖治愈的播客片尾配乐。
钢琴 + 木吉他 + 轻弦乐，情绪平和略带一点回味的收束感，
中后段缓缓变薄，最后 10 秒只剩钢琴与轻微 pad 自然淡出。
动态平缓，音量整体低于片头水平的人声位；不要新的旋律动机，不要人声。
```

### 案例 P7 · 开场 riser + 落点（预告/发布会开场）
```
纯音乐，无人声。一段 8 秒的开场配乐。

第 6 秒：一个厚重的低频落点（hit）加铜管短音；
第 7–8 秒：留白，只剩余韵，方便接标题字幕。
气势强、有压迫感与仪式感；不要提前泄力，不要人声，不要口哨。
```

## 六、纯音乐的高频失败与改法

| 症状 | 改法 |
|---|---|
| 老是冒出人声 | 提示词开头/中间/结尾三处都写"纯音乐无人声"；仍不行就用音轨分离删人声轨 |
| 有时写着纯音乐却有大段前奏慢慢铺垫，进正题太慢 | 写"第 3 秒内进入主体"，或直接用 sting/loop 结构要求 |
| 循环不起来、接不上 | 加"首尾对齐、可无缝循环、不要明显的开始与结尾" |
| 配旁白时歌词被压住（虽然无人声但旋律太满） | 加"旋律密度低、中频留白、整体退后，不抢台词" |
| 低频轰头 | 加"低频干净不轰头，减少 sub bass" |
| 听起来像半成品 demo | 加"整体干净通透、动态舒展、结尾自然收束"；导出前做一次智能母带 |
| 太短/拖沓 | 明确写总时长：15s / 30s / 60s，并写"尾奏控制在 X 秒内" |
| 缺少记忆点（纯音乐也需要一点钩子） | 指定一个专门的音色做钩子（"口哨旋律"、"马林巴动机"） |

## 七、批量出系列 BGM（做账号矩阵）

固定母版，只换变量，保证账号听觉统一：

```
母版：纯音乐，无人声。一段轻快治愈的纯音乐 BGM，木吉他 + 马林巴 + 手拍，
BPM 112，明亮温暖，动态平缓不抢画面，60 秒可循环。
共 5 版，每版只改一处：
```
