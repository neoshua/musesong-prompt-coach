# 音域应用专章：高音 / 中音 / 低音各自适合什么

> 适用于：定人声时选音区；副歌要不要上高音；用户只给了情绪/场景描述时反推音域；用户抱怨"高音像喊""低音听不清"时的修法。
> 一句话：**音色决定"什么人在唱"，音域决定"在哪个高度唱"——同一个质感放在不同音区，是完全不同的歌。**

---

## 一、先分清两个维度：音色 ≠ 音域

| 维度 | 管什么 | 典型词 | 写错的后果 |
|---|---|---|---|
| 音色（质感） | 什么人在唱 | 温暖、沙哑、气声、烟嗓、少年感 | 得到"平均音色"，不对味 |
| 音域（音区） | 在哪个高度唱 | 低音区、中音区、高音区、假声、头声 | 情绪坐标错位：深夜歌用了明亮高音，释怀歌窝在低音区 |

**模型把音域当软约束**：单独甩一个"高音"可能被忽略，甚至演变成喊叫。有效写法是三件套一起给：**音区 + 位置（哪个段落）+ 质感（通透/假声/胸腔共鸣）**。

---

## 二、男女声的绝对音高差（先避这个坑）

- 女声整体比男声高**约一个八度**：**女声的"中音区"≈ 男声的"高音区"**。跟用户沟通时先用听感高度（低沉 / 居中 / 明亮），确认后再决定要不要给专业模式的绝对描述。
- **对唱 / feat 必须写分层**，否则两个声部挤在同一音区互相打架：
  > `男女对唱：男声低八度和声，女声高八度主旋律，声部分层清晰`

---

## 三、三个音区的专业画像

| 音区 | 听感关键词 | 声学与演唱特征 | 情绪与叙事功能 | 不适合 |
|---|---|---|---|---|
| **低音区** | 浑厚、沉稳、压迫感、安全感、叙事者视角 | 基频低、能量集中在中低频、胸腔共鸣；**咬字容易糊，需刻意保持清晰** | 深沉、悬疑、史诗、成熟、慵懒、深夜 emo、权威感（旁白/导师视角） | 快嘴密集歌词、儿童向、明快广告（会显得拖/暗） |
| **中音区** | 温暖、亲切、自然、电台感、真诚 | 人声最自然的音区，与日常说话重叠，**听众最省力**，最像"讲述" | 治愈、日常、信任、婚礼、口播、企业宣传——"不会错"的默认区 | 需要强烈爆点的副歌（单独用会显得平） |
| **高音区** | 明亮、空灵、穿透、仙气、金属光泽、释放 | 高频泛音带来亮度与穿透力；分**假声/头声（轻）**与**真声强（力量）**两种质地 | 释放、爆点、宏大、青春、仪式感、仙侠、空灵氛围 | 长时间铺底（累 + 抢注意力）、悬疑压迫（会泄劲） |

## 四、情绪 × 场景 → 音域决策表（核心，按用户给出的情绪/场景查）

| 用户给的情绪 / 场景 | 推荐音区 | 提示词要点 |
|---|---|---|
| 深夜独处、压抑、悬疑、emo、失恋、疲惫 | **低音区** | 男声低音区胸腔共鸣 / 慵懒女低音气声；必写"咬字清晰、不闷" |
| 温暖治愈、日常 vlog、口播、知识类、婚礼、企业宣传 | **中音区**（默认最稳） | 温暖亲切"像在讲述"；低动态，不炫技 |
| 释怀、告白、毕业、逆袭、情绪爆点 | **主歌中低音区 + 副歌上高音区** | 用音域对比制造爬升感；写"过渡自然" |
| 空灵、仙侠国风、禅意、冥想、仪式感 | **高音区假声/吟唱** | 气声多、混响大；国风可加"戏腔高音吟唱、真假声转换" |
| 派对、卡点、夜店、运动 | **低音区 + 电子/说唱 flow**，或高音区短句 hook | 看要不要人声当主角 |
| 史诗预告、品牌大片 | **低音区压迫叙事**（旁白视角）或 **高音区宏大**（升华视角） | 先问"这段音乐是谁在说话" |
| 功能型背景（学习/专注/长时垫底，带人声的歌曲也适用） | **中音区 + 低动态** | 稳定不炫技，不要突然拔高 |

> 用户说"你定"时的默认答案：**中音区**；只有当他明确要"被记住/要炸/要空灵"时，才上高音区设计。

## 五、段落内音域设计（比整曲一个音区更专业）

- **经典三段动态（最推荐）**：主歌中低音区克制叙事 → 预副歌过渡 → 副歌高音区爆发 → 尾奏回落
- **稳定型**：全曲中音区、音域跨度小 → 耐听、氛围向、口播友好
- **混合型**：主歌低音区呢喃 → 副歌高音区释放 → 桥段假声 → 尾奏渐弱
- **跨度控制**：AI 模型对"音域跨度太大"的处理容易撕裂、转音突兀。流行歌写 `音域跨度自然、过渡平滑`；国风/戏腔才写 `真假声转换`。

可直接抄：

```
主歌中低音区克制叙事，副歌进入高音区爆发，音域过渡自然，尾奏回落到中音区渐弱
全曲保持中音区，音域跨度小，稳定不炫技，适合长时间播放
```

## 六、可直接抄的提示词片段（按音区）

**低音区**
```
男声低音区，胸腔共鸣，低沉浑厚但不闷，咬字清晰
慵懒女低音，贴耳气声，慢速叙事，像深夜电台
男声低音区念白式演唱，克制，不吼不喊
```

**中音区**
```
女声中音区，温暖亲切，咬字自然，像在讲述自己的故事
男声中音区，质朴稳重，适度转音，不过度炫技
```

**高音区**
```
副歌进入高音区，通透有金属光泽，强而通透，不是嘶吼
空灵高音区，假声轻唱，带气声与延迟混响，仙气飘飘
桥段加入戏腔高音吟唱，真假声转换自然
```

**音域动态与负向约束**
```
主歌中低音区克制，副歌上高音区爆发，音域过渡自然
不要全程高音
副歌之外不要突然拔高
不要嘶吼式高音，要通透有光泽
男女对唱：男声低八度和声，女声高八度主旋律，声部分层清晰
```

## 七、常见翻车与修法

| 症状 | 原因 | 改法 |
|---|---|---|
| 高音变喊叫/撕裂 | 只写"高音/爆发"，模型默认用喊 | 改"通透/有光泽/头声/假声"，负向加"不要嘶吼" |
| 低音糊成一片听不清 | 低音区 + 慢速 + 密配器，中低频打架 | 写"咬字清晰、低音干净不闷"；配器减低频，给中高频让位 |
| 音域跳转换来撕裂感 | 跨度过大且没写过渡 | 写"音域跨度控制在自然范围、过渡平滑" |
| 全程一个高度，听着平 | 没设计段落音域对比 | 主歌中低、副歌高，制造爬升 |
| 对唱两个声部挤在一起 | 没写分层 | 男低八度/女高八度，或"一主一和" |
| 高音副歌听着累 | 全程高能无张弛 | 副歌高、主歌回中低，张弛交替 |

## 八、曲风默认音区速查

| 曲风 | 默认音区 | 备注 |
|---|---|---|
| 华语抒情流行 | 中音区 + 副歌上高音 | 最经典的爬升结构 |
| R&B / Neo Soul | 中低音区 | 转音多，慵懒 |
| 民谣 / 治愈 | 中音区 | 稳，像聊天 |
| 国风 / 戏腔 | 中低叙事 + 桥段戏腔高音 | 吟唱段是高音区 |
| EDM / 电子 | 高音区短句 hook 或低音区说唱 | 看人声是不是主角 |
| Lo-fi / 慢摇说唱 | 中低音区 / 低音区 | 慵懒、flow 叙事 |
| 摇滚 / 力量 | 中音区主歌 + 高音区力量副歌 | 要 raw 质感才显式写"嘶吼" |
