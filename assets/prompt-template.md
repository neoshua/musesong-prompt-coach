# 提示词模板与速查卡（可复制给用户随身携带）

## 一、万能填空模板（复制到备忘录里填）

```
【作品类型】 □带人声歌曲  □纯音乐BGM  □改编（翻唱/仿写/续写）  □AI MV

【场景画面】在______（时间），______（地点），______（谁在做什么）
【情绪走向】从______ 到______（例：从疲惫沉默 到 慢慢释怀）
【主曲风】______（例：华语流行抒情）
【融合元素】______（例：一点 R&B 松弛感 / 副歌加轻量电子鼓）
【主奏乐器】______为主，______为辅
【人声】□男声 □女声 □对唱 □无人声；质感：______；限制：______
【速度】BPM ______（或体感：很慢/舒缓/中速律动/明快/快）
【结构】□完整单曲（约3分钟） □短视频版（60~90秒） □循环Loop（15~30秒）
【质感】□干净通透 □电影感 □Lo-fi □黑胶温暖 □极简留白 □低频饱满
【不要】1.______ 2.______ 3.______（最多三条）
```

## 二、成文法：把上面填好的内容连成一句话

```
一首[主曲风]，[融合元素]点缀；画面是[场景画面]，情绪从[起点]到[终点]；
[主奏乐器]为主、[辅助乐器]为辅；[人声描述]，[人声限制]；
BPM [x]，[情绪/动态走向]；结构为[结构]，时长约[x]；
整体[质感]，[人声与伴奏关系]；不要[排除项]。
```

## 三、一页速查卡

**九要素权重**：类型 → 场景+情绪 → 曲风融合 → 乐器 → 人声 → BPM → 结构 → 质感 → 排除

**BPM 体感对照**
| 体感 | BPM | 典型场景 |
|---|---|---|
| 极静/深夜 | 60–72 | 冥想、回忆、慢镜头 |
| 抒情 ballad | 76–88 | 华语情歌主流区间 |
| 中速律动 | 92–104 | 民谣、City Pop、vlog |
| 明快日常 | 110–124 | 旅行、校园、日常记录 |
| 强节奏 | 126–140 | EDM、卡点、运动 |
| 说唱 | 85–100（慢摇）/ 140+（快嘴） | 叙事 / 态度 |

**高频"不要"词库**（最多挑 3 条）
不要 rap · 不要配器堆砌 · 不要重金属失真 · 不要过度 AutoTune 电音感 · 不要过快 · 不要过慢 · 不要哭腔 · 不要悲痛撕心裂肺 · 不要乐器堆满（国风必加） · 不要突然的音量变化（BGM 必加） · 不要英语单词（歌词纯净度）

**常用动词/形容词**
推动（渐强）· 铺垫 · 抽空（只剩人声）· 齐奏 · 渐弱收束 · 留白 · 通透 · 湿润 · 颗粒感 · 空气感 · 贴耳 · 克制 · 停顿半拍
