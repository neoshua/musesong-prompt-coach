# 提示词模板与速查卡（可复制给用户随身携带）

> **v2.1（2026-11-05）**：官方公式、纯音乐字段、标签语言、模型清单见 `../references/12-official-guide.md`（✅ 官方唯一权威）。技能规则按 **A 官方硬约束 / B 效果红线 / C 默认做法** 三层执行：A 层必守；B/C 层（五件套、九要素清单、两轮上限、拆两段排版）是 🧩 自研默认做法，用户一句话可改、多轮迭代可精简。实战章见 `13`–`17`。

## 一、万能填空模板（复制到备忘录里填）

```
【作品类型】 □带人声歌曲  □纯音乐BGM  □改编（翻唱/仿写/续写）  □AI MV

【场景画面】在______（时间），______（地点），______（谁在做什么）
【情绪走向】从______ 到______（例：从疲惫沉默 到 慢慢释怀）
【主曲风】______（例：华语流行抒情）
【融合元素】______（例：一点 R&B 松弛感 / 副歌加轻量电子鼓）
【主奏乐器】______为主，______为辅
【人声】□男声 □女声 □对唱 □无人声；质感：______；音域：□低音区 □中音区（默认） □高音区；限制：______
【速度】体感：□很慢 □舒缓 □中速律动 □明快 □快；BPM ______（**仅卡点/舞曲/EDM 填**；官方 `WNB:124` 不建议写词类硬定 BPM）
【结构】□完整单曲（约3分钟） □短视频版（60~90秒） □循环Loop（15~30秒） □**副歌前置**（传播向首选）
【质感】□干净通透 □电影感 □Lo-fi □黑胶温暖 □极简留白 □低频饱满
【不要】1.______（可选，最多 1~2 条，不是必填）
【成文长度】官方建议 **30-60 个词**效果最好（`FKQK:262`）；风格栏上限 2000 字 / 歌词栏 5000 字。**没有 500 字符硬限**
【纯音乐必做】在**歌词栏**填 `[Instrumental]`（或 `[Inst]`）或打开纯音乐开关，字段变灰才生效（`XieP:366`）；风格栏写 `Instrumental` + 曲风/配器，不写 `[Verse]`/`[Chorus]`。中文「纯音乐」单词有概率失效，优先英文
```

## 二、输出格式：带人声拆「风格提示词 + 歌词」两块（本技能约定，便于分别粘贴）

```
【风格提示词】（粘妙响「风格栏」，只写声音，30-60 词为佳）
[主曲风]+[融合]，[氛围/情绪]，[主奏乐器]，[人声描述]，[质感]；卡点类才加 BPM。

【歌词】（粘「歌词框」，半角 [] 分段；优先英文段名，中文段名亦可，全篇统一）
[Intro]
[Music: 钢琴单音，雨夜环境音]

[Verse 1]
[Vocal: 贴耳气声，克制]
第一行
第二行

[Pre-Chorus]
推进句

[Chorus]
[Music: 加入弦乐与鼓组]
[Vocal: Belting]
副歌金句（15 秒内出，全曲重复≥3 次）

[Outro]
(Whisper)
收尾句
```

> **分段指令必须在歌词正上方**（`Jdxf:41`）；配器/人声可分写 `[Music: …]` / `[Vocal: …]`。
> 标点只用 `，！？。[] ()`；演唱指令 `(Breath)` `(Sigh)` `(Whisper)`、行尾 `...` 可嵌入。
> **段名硬约束**：半角 `[]` + 结构名正确 + 全篇统一。官方 `JauM:158`「方括号中中文和英文都可」；旧版「禁用中文段名」已废止。

> 纯音乐BGM：**风格提示词 + 歌词栏指令 `[Instrumental]`** 两块；也可直接打开纯音乐开关。不要只给一段风格描述。

## 三、成文法：按官方公式组装（先定骨架 → 氛围 → 乐器人声 → 细节）

官方核心公式（`FKQK:244`）：`[结构 + 风格 + 氛围 + 乐器 + 人声 + 其他细节]`

```
[主曲风][融合]，[氛围/情绪走向]，[主奏乐器] led by，[人声描述]，[制作质感]。
```
* 卡点/EDM/动感流行按曲风公式加 `[速度BPM]`；民族国韵加 `[核心民族乐器]`；Rap 加 `[律动描述]`。见 `12` 章第二节。
* 想留白就用宽泛词（`keyboard melody`），要写死就写明（`piano melody`）；优先级词 `Led by / Focus on`，弱化词 `Subtle / A hint of`。
* **迭代只改 3-5 个词**（`FKQK:389`），不要整段重写。

## 四、一页速查卡

**官方公式**：结构 + 风格 + 氛围 + 乐器 + 人声 + 其他细节（30-60 词）；按曲风再选四条专用公式之一。〔九要素清单是本技能「把灵感问全」的内部检查表，不要全塞进提示词〕

**纯音乐官方机制**：歌词栏填 `[Instrumental]` / `[Inst]` 或开纯音乐开关；风格栏写 `Instrumental`。中文「纯音乐」不可靠，优先英文。**无 500 字符上限、不需三处「无人声」**。

**音域速选**：压抑/深夜/悬疑 → 低音区；温暖/日常/真诚 → 中音区（默认）；释放/爆点/空灵 → 高音区（副歌上高）。

**BPM 体感对照**（仅卡点/舞曲/EDM 类写死；写词/抒情类官方不建议写 BPM）
| 体感 | BPM | 典型场景 |
|---|---|---|
| 极静/深夜 | 60–72 | 冥想、回忆、慢镜头 |
| 抒情 ballad | 76–88 | 华语情歌主流区间 |
| 中速律动 | 92–104 | 民谣、City Pop、vlog |
| 明快日常 | 110–124 | 旅行、校园、日常记录 |
| 强节奏 | 126–140 | EDM、卡点、运动 |
| 说唱 | 85–100（慢摇）/ 140+（快嘴） | 叙事 / 态度 |

**高频"不要"词库**（最多挑 3 条）
不要 rap · 不要配器堆砌 · 不要重金属失真 · 不要过度 AutoTune 电音感 · 不要过快 · 不要过慢 · 不要哭腔 · 不要悲痛撕心裂肺 · 不要乐器堆满（国风必加） · 不要突然的音量变化（BGM 必加） · 不要英语单词（歌词纯净度）

**常用动词/形容词**
推动（渐强）· 铺垫 · 抽空（只剩人声）· 齐奏 · 渐弱收束 · 留白 · 通透 · 湿润 · 颗粒感 · 空气感 · 贴耳 · 克制 · 停顿半拍

**输出两段约定**：带人声 → 「风格提示词」（粘风格栏）+「歌词」（粘歌词框）；纯音乐 → 「风格提示词」+「歌词栏 `[Instrumental]`」两块。

**歌词标签速查**：结构 `[Intro]`/`[Verse 1]`/`[Pre-Chorus]`/`[Chorus]`/`[Bridge]`/`[Outro]`/`[Instrumental]`；中文同名 `[前奏]`/`[主歌1]`/`[副歌]` 亦可；人声/唱法 `[Female Vocal]`/`[Male Vocal]`/`[Duet]`/`[Whispered]`/`[Spoken]`/`[Belted]`/`[Falsetto]`/`[Harmonized]`；分段指令 `[Music: …]`/`[Vocal: …]`。纪律：半角 `[]`、结构名正确、全篇语言统一、标签独占一行、段间空一行、分段指令放歌词正上方、副歌每次贴全词。

**官方纠错字三修法**：① 同音字替换后「只改编歌词，其他不动，重新生成」；② 音乐改编·翻唱（改词保曲，参考音频权重 8-9、风格权重与创意发散尽量低）；③ 音色替换**不能**改错字。

**金句四公式**（`WNB:265-269`）：自我和解 / 遗憾留白 / 细节扎心 / 温柔自愈；核心金句 15 秒内出、全曲重复 ≥3 次；避开 AI 高频意象「便利店、关东煮、地铁」。

**官方模型**：音乐 Sway v5.0 / v5.5；AI MV 视频 Seedance 2.0 / 2.5。
