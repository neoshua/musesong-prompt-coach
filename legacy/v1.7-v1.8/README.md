## 使用前的注意（重要）

这些章节写在官方知识库精读**之前**，下面几条口径已在 v2.0 被官方原文推翻，**不要直接搬回主线**：

- 纯音乐「≤500 字符 + 开头/中间/结尾三处写无人声」→ 官方走**歌词栏 `[Instrumental]` / `[Inst]` 或纯音乐开关**（`XieP:366`）；中文「纯音乐」单词有概率失效（`Om77:68-70`）。
- 「禁用中文段名、必须全英文标签」→ 官方 `JauM:158`「方括号中中文和英文都可」、`Jdxf:71`「元标签不区分大小写」；硬约束是半角 `[]` + 结构名正确 + 全篇统一。
- 模型清单含 SeedMusic / Mureka / Sodance → 官方音乐模型只有 **Sway v5.0 / v5.5**，AI MV 视频是 **Seedance 2.0 / 2.5**。
- 万能公式必写 BPM / 必写「不要什么」→ 官方核心公式是 `[结构+风格+氛围+乐器+人声+其他细节]`，另四条按曲风分发；`WNB:124` 不建议写词类硬定 BPM（**仅限「AI 作词 → 用歌词生成歌曲」流程**，纯音乐/卡点/EDM 不受限）。
- 提示词「60~120 字 / 80~150 字」「重复关键要素 2 次提高权重」→ 官方建议 **30-60 个词**（`FKQK:262`），重复加权是第三方 Suno 说法，官方 32 篇无据。

**仍然有效、可考虑合并的部分**：v1.7 五章的实战沉淀、v1.8 的「三条硬规则」精简取向、五条写词实战规则，都属于本技能自研经验，官方 32 篇未提及但**不与官方冲突**（判定原则：自研 ≠ 错，只改与官方冲突/内部自相矛盾/冒充官方的部分）。若要合并，需按 `references/12-official-guide.md` 逐条校对后重新编号纳入。
